## 처음 시작
`이 저장소의 CLAUDE.md 를 읽고, 내 이름으로 복사해 내 사이트로 만들어 줘. 사이트 이름은 <이름>, 주제는 <주제>. 내가 해야 하는 건 그때 멈추고 물어봐.`

## 하루 한 바퀴
`런북.md 를 읽고 1절 순서대로 오늘 한 바퀴 돌려. 올리기 전에 check.py 를 통과해야 해. 막히면 기록에 남기고 멈춰.`

## 피드 바꾸기
`feeds.json 에 <주제> 관련 RSS 를 찾아 넣어 줘. 주소는 직접 열어서 200 과 기사 수를 확인하고, 안 열리면 빼고 이유를 적어.`

## 세션 하나로 돌리기
`역할/세션하나로.md 를 읽고 기획·개발·마케터·홍보를 한 세션에서 차례로 해 줘.`

## 쇼츠 영상 만들기
`shorts.py 를 돌려서 오늘 확인 노트로 쇼츠 영상을 만들어 줘. ffmpeg 나 브라우저가 없으면 설치 방법을 알려 주고, 다 만들면 영상 한 편을 열어 길이·해상도·글자 잘림을 확인해서 알려 줘. 유튜브에 올리는 건 내가 로그인한 다음에 할 테니 영상과 제목·설명 파일만 준비해 둬.`
