먼저 `과외.md`(수업 방식)를 읽고 그대로 따른다: 독자 파일 확인 → 한 걸음마다 한 줄 안내 → 돌리기 → 두세 줄 설명 → 독자가 해 볼 일 하나 → 확인 물음 하나.
인자 $ARGUMENTS (이름 또는 「전부」, 없으면 목록을 보여 주고 고르게 한다).
1. `python run.py 키트 $ARGUMENTS` 를 돌린다 — 꼭 알아야 할 것 3가지 → 보이는 브라우저에서 스스로 시험 → 바꿔 보기 제안 순서로 나온다.
2. `kits/<이름>/설명.md` 가 있으면 그 뼈대로 풀어 설명한다(CLAUDE.md 「설명하는 법」).
3. 시험의 ✓/✗ 를 그대로 보고한다. ✗ 가 있으면 고치지 말고 어느 단계가 왜 안 됐는지 먼저 말한다.
4. 마지막에 확인 물음 세 개와 「바꿔 보기」 제안을 낸다.

공통 규칙: 올리기(push·deploy)·메일 발송·로그인·결제는 하지 않는다(필요하면 멈추고 사람에게 한 줄로 묻는다). 한국어로, 독자 눈높이로 말한다. 진도는 run.py 가 자동으로 적으므로 따로 적지 않는다(run.py 를 안 거친 일만 `python run.py 진도 기록 <한 일>`).
