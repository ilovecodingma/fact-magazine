# 2장 — 쿠팡 같은 가게를 내 것으로 (화면 Next.js · 백엔드 파이썬 · 앱) — 결제만 빼고
먼저 `과외.md` 를 읽는다. 흐름은 1장과 같다. 달라지는 것은 **방문자가 담고, 주문하고, 평을 남긴다**는 것이고 그래서 백엔드가 붙는다. 독자는 프롬프트 몇 줄만 친다.
**도착점: 「쿠팡 같은 가게가, 휴대폰 앱까지, 오늘 안에 내 것으로?」**
템플릿은 종합 쇼핑몰의 짜임(찾기·분류·상품·장바구니·주문·상품평·찜·인기 순위·쿠폰·운영자)을 본뜬 것이다. 남의 가게 이름·로고·상품 사진·문구는 쓰지 않는다 — 처음부터 독자의 가게로 만든다.

## 0. 띄우고, 주소를 받는다 (세션이 혼자) — 관문 「만들었다」「올렸다」
`python run.py 본 가게 --열쇠 <운영자 열쇠>` → 이어서 묻지 않고 `python run.py 올려 가게`. 운영자 열쇠는 묻지 않고 세션이 길고 어려운 말로 하나 정해 독자에게 알려 준다(바깥에 열리는 주소라 쉬운 말은 안 된다. 독자가 나중에 바꿀 수 있다). 처음에는 화면에 필요한 것과 바깥 주소를 붙이는 프로그램을 받느라 1~2분. Node.js 가 없으면 그 한 줄을 알리고 독자가 깔 때까지 기다린다.
주소가 나오면 건넨다: 「가게가 인터넷에 열렸습니다. 이 주소를 휴대폰으로 열어 상품을 하나 담아 주문까지 해 보세요. 무통장 입금 방식이라 주문이 들어오면 제가 알려 드립니다.」 → 독자가 주문하면 `python run.py 데이터 현황` 으로 들어온 주문을 읽어 주고 운영자 화면(`<주소>/admin`)을 알려 준다.
이 주소는 이 PC 와 가게가 켜져 있는 동안 열린다(로그인 없음). 주제를 처음 한 줄에 적었으면 1절의 ①②③을 먼저 채운 뒤에 주소를 낸다.

## 1. 내 가게로 — 세 줄
| # | 건네는 말 (보기) | 세션이 고치는 곳 |
|---|---|---|
| ① | 가게 이름과 색을 정해 볼까요? 예) *이름은 숲속 캠핑 상점, 색은 짙은 초록* | `shop/web/site.json` 의 name·tagline·color·banner |
| ② | 무엇을 파는 가게인가요? 예) *캠핑 용품 — 텐트, 의자, 랜턴, 버너 같은 것* | `shop/api/data/products.json` 을 독자의 상품으로(분류 4개, 분류마다 4개. 값과 설명은 독자가 말한 것으로, 말하지 않은 것은 「이렇게 넣어 두었습니다, 고쳐 주세요」 하고 보인다) → 상품마다 사진: `python photo.py "<영어 낱말>" shop/web/public/p/<번호>.jpg --square`(받은 사진을 열어 보고 안 맞으면 `--pick 2`), 큰 띠 사진 `shop/web/public/hero.jpg` → `python run.py 가게 상품다시` |
| ④ | (묻지 않는다 — 안내만) 「입금받을 계좌는 저에게 말하지 말고, 운영자 화면(`/admin`)의 「입금 계좌」 칸에 직접 넣어 주세요.」 | **세션은 계좌 번호를 받지도, 적지도, 읽지도 않는다.** 독자가 대화에 계좌를 적으면 「그 번호는 화면에 직접 넣어 주세요」라고 하고 파일에 옮기지 않는다. 계좌는 `shop/api/data/bank.local.json` 에만 남고 git 에 올라가지 않으며 세션이 읽지 못하게 막혀 있다. 넣지 않으면 주문 뒤에 「판매자가 입금 계좌를 따로 안내드립니다」로 나온다. 주문은 무통장 입금 방식이다(주문 → 입금 대기 → 운영자가 입금 확인 → 보냄) |
| ③ | 첫 화면 큰 띠에 뭐라고 쓸까요? 예) *이번 주말, 첫 캠핑 준비 끝* | `shop/web/site.json` 의 banner |

고칠 때는 1장과 같이 `python run.py 바꿔 "<독자의 말>"` → 고침 → `python run.py 바꿨다 "<한 일>"`. 화면은 켜 둔 채로 저절로 바뀐다(Next.js 가 고친 것을 바로 다시 그린다).

## 2. 붙였다 뗐다 — 이 장의 볼거리
「기능을 말 한 줄로 붙였다 뗄 수 있습니다. 해 볼까요? 예) *상품평 떼 줘* / *쿠폰 떼 줘* / *인기 순위 다시 붙여 줘*」
`python run.py 떼 <기능>` · `python run.py 붙여 <기능>` · `python run.py 기능`. 서버를 끄지 않아도 몇 초 안에 화면에서 사라지고 돌아온다. 뗀 기능의 자료(남긴 상품평 등)는 지워지지 않아 다시 붙이면 그대로다 — 이것을 눈으로 보인다.
없는 기능을 말하면(예: *상품 문의 게시판* / *최근 본 상품* / *타임 세일 남은 시간*) 새로 만든다: `shop/api/modules/<이름>.py` 한 파일(ROUTES 와 init) + 화면에 그 자리. 만든 뒤 `python run.py 붙여 <이름>`.

## 3. 틀어 본다 — 겉모습은 그대로, 가게의 방향을
「같은 가게가 한 줄에 다른 가게가 됩니다. 예) *이걸 동네 반찬 가게 예약 주문으로* / *중고 책방으로* / *수업 신청 받는 곳으로(장바구니 대신 신청하기)*」
이름·색·짜임은 그대로 두고 상품 자료·말(「장바구니」→「신청함」 같은 낱말)·붙은 기능만 바꾼다. 걸린 시간을 그대로 말하고 전·후를 보인다. 마음에 안 들면 `python run.py 되돌리기`.

## 4. 앱으로 — 휴대폰에 깐다
「휴대폰에 앱으로 깔아 볼까요?」 같은 와이파이에서 이 PC 의 주소(세션이 알려 준다: `http://<이 PC 의 주소>:3000`)를 휴대폰으로 열고 「홈 화면에 추가」. 아래 메뉴가 있는 앱 모양으로 뜬다. (주소를 올린 뒤에는 그 주소에서 깔면 어디서나 된다 — 앱은 사이트에서 바로 깔리는 방식이다.) 앱 장터(애플 앱스토어·구글 플레이)에 올리고 싶다고 하면 `올리기.md` 의 「앱 장터에 올리려면」을 읽어 길과 드는 값을 알려 준다(개발자 계정 값을 치르고 심사를 받아야 하며, 가입·결제·제출은 독자가 한다).

## 5. 스스로 눌러 본다
`python run.py 가게 시험` — 방문자·운영자 노릇으로 15단계(찾기·담기·찜·상품평·주문·쿠폰·운영자 처리·기능 떼기와 붙이기). 걸린 것은 말하고 고친다.

## 6. 계속 열어 두려면
0절에서 받은 주소는 이 PC 와 가게가 켜져 있는 동안만 열리고, 다시 열면 주소가 바뀐다. 가게를 고친 뒤에는 화면이 저절로 따라가므로 다시 올릴 것이 없다(껐다 켰으면 `python run.py 올려 가게` 로 새 주소).
- 하루 종일 열어 두려면 하나만 묻는다 — 「이 PC 를 계속 켜 둘 수 있나요?」 켜 둘 수 있으면 지금 방식 그대로 두고, 바뀌지 않는 주소를 붙이는 길(내 도메인 + Cloudflare 가입)을 `올리기.md` 에서 알려 준다. 아니면 작은 서버에 `shop/` 을 그대로 올리는 길을 알려 준다. 가입·결제는 독자가 한다.
- 결제는 붙이지 않는다(무통장 입금). 손님이 몰려 서버를 늘려야 하는 일은 지금 단계에서는 고려 대상이 아니다.

## 7. 맺는다
