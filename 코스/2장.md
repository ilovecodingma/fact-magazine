# 2장 — 조립 (키트를 섞어 사이트로)
먼저 `과외.md` 를 읽고 그 방식(독자 묻기·한 걸음의 짜임·확인 물음·기록)으로 진행한다. 이 장에서는 「왜 이 기능들인지」 고르는 까닭을 가르친다(과외.md 5절).
목표: 조립 예시를 둘러보고 둘을 골라 독자 이름·자료로 바꿔 자기 PC 에서 연다.

1. `python run.py 조립` 으로 목록을 보여 주고, 이름은 한글(도구함·동네 정보·정보 매거진)이나 key(tools·town·magazine) 둘 다 된다. `/조립 도구함`, `/조립 동네 정보`, `/조립 정보 매거진` 을 차례로 둘러본다(메뉴를 하나씩 눌러 보는 시험 포함).
2. **독자가 둘을 고른다.** 둘을 합친 사이트는 `/섞기 도구함+동네정보` (= `python run.py 섞기 도구함+동네정보`) 한 줄로 만든다 — 예시 이름을 `+` 로 이으면 두 예시의 키트가 합쳐지고, 키트 이름(계산기·용어·일정…)도 한글로 섞어 쓸 수 있다(`/섞기 도구함+일정`).
3. **독자 것으로 바꾸기 — 독자에게 이렇게 묻는다**(한 번에 하나, 임의로 정하지 않는다):
   - (주제를 바꾸는 매거진 계열이면 먼저) 「예시로 들어 있는 확인 노트(2026-11-11-…)를 예제/ 폴더로 옮길까요?」 — 옮길 때만 `python run.py 예제정리 --yes`.
   - 사이트 이름: 「이름을 무엇으로 할까요?」 → `site.local.json` 의 `name`.
   - 한 줄 소개: 「사이트를 한 줄로 소개하면?」 → `tagline`(첫 화면 제목 밑 한 줄). 소개 쪽 `about` 은 **두세 문장**으로 받는다(너무 짧으면 점검이 「빈 쪽」으로 잡는다).
   - 자료: 도구함이면 「자주 쓰는 용어 세 개」(`kits/glossary/data/terms.json`), 동네 정보면 「일정 세 개」(`kits/schedule/data/events.json`)와 「링크 다섯 개」(`kits/links/data/`), 매거진이면 「다룰 분야」(`topic_keywords`).
   - **켜진 키트마다 한 줄씩 묻는다**(예시 주제가 그대로 남지 않게):
     | 키트 | 물을 것 | 바꿀 파일 |
     |---|---|---|
     | 비교표 compare | 비교할 것 하나와 열 3개(예: 요금제·가격·특징) | `kits/compare/data/table.json` |
     | 퀴즈 quiz | 내 주제 문제 3개와 정답 | `kits/quiz/data/quiz.json` |
     | 용어 glossary | 용어 3개 | `kits/glossary/data/terms.json` |
     | 일정 schedule | 일정 3개(날짜·이름) | `kits/schedule/data/events.json` |
     | 링크 links | 링크 5개 | `kits/links/data/links.json` |
     | 질문 faq | 자주 받는 질문 3개 | `kits/faq/data/faq.json` |
     | 공지 notice | 알릴 말 한 줄 | `kits/notice/data/` |
     | 위키·글 | 글 제목 3개 | `kits/wiki/data/*.md` |
     | 사진첩 gallery | 그림 이름 3개 | `kits/gallery/data/captions.json` |
     | 타임라인 timeline | 있었던 일 3개 | `kits/timeline/data/timeline.json` |
     | 디데이 dday | 기다리는 날짜 3개 | `kits/dday/data/dates.json` |
     | 요리법 recipes | 요리 3가지 | `kits/recipes/data/recipes.json` |
4. `python serve.py --open` 으로 내 PC 에서 연다(주소 줄은 바로 출력되고, 8000 이 쓰이는 중이면 8001 처럼 다음 번호로 열린다).
5. **마지막 걸음 — 앱처럼 만들기(PWA)**: `/키트 앱` 으로 보는 앞에서 시험한다(설치 가능 확인 → 가계부에 12,000원 적기 → 인터넷 끄기 → 다시 열어도 열리고 값이 남음). 이어서 `/조립 가계부` 로 완성 예시(한입 가계부)를 열고, 「홈 화면에 추가하는 법」(PC 주소창 설치 아이콘·폰 메뉴)을 안내한다. 설명 뼈대는 `kits/pwa/설명.md`. 127.0.0.1 은 이 PC 연습용이고 다른 기기 설치는 https 공개 주소가 필요하다는 점, 웹 앱과 스토어 앱의 차이(개발자 계정·심사는 글로만 안내, 이 코스에서는 올리지 않음)를 말한다.
올리기·가입은 하지 않는다.
