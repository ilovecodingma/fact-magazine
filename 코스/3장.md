# 3장 — 운영팀을 만든다: 내가 없어도 돌고, 알려지고, 관리된다
먼저 `과외.md` 를 읽는다. 만드는 데까지는 세션 하나로 충분했다. **세션을 여럿으로 나누고 서브에이전트에게 맡기는 것은 운영부터다.** 이 장은 묻지 않고 끝까지 도는 것이 기본이고, 세션은 일을 벌여 놓고 결과 한 장을 내민다.
**도착점: 「내가 출근해 있는 동안에도 글이 올라가고, 메일이 나가고, 알릴 글·그림·영상이 만들어지고, 주문과 자료가 관리된다고?」** 튜토리얼은 여기서 끝난다.

출력마다 두 줄을 갈라 말한다: **사람 없이 된 것 / 여기서 사람이 승인(로그인)하면 이어지는 것.**

## 1. 자동 운영을 먼저 본다 (세션이 혼자)
「지금부터 제가 아무것도 묻지 않고 하루치 일을 끝까지 해 보겠습니다.」
`python run.py 자동 맛보기` → 끝나면 `넘김/자리비운동안.md` 를 읽어 주고 만들어진 블로그 글·카드 그림·영상을 하나씩 열어 보인다. 이어서 「2분 뒤에 저절로 돌게 해 두겠습니다. 다른 일을 하다 오세요」 → `python run.py 자동 맛보기 --뒤 2`.

## 2. 운영팀의 짜임을 보인다
한 장으로 말한다(그림은 책에 있다): **사람 → 총괄 세션 → 역할 세션 셋(개발·콘텐츠·홍보) → 각 세션이 부리는 서브에이전트 → 예약 작업 → 쌓이는 자료.**
| 맡는 곳 | 하는 일 | 건드리는 것 |
|---|---|---|
| 총괄 | 일을 나누고, 사람에게 물을 것을 모으고, 결과를 한 장으로 | `넘김/` `기록/` |
| 개발 | 사이트·가게를 고치고 올린다, 자료를 백업한다 | 저장소 파일, `run.py 올려`, `run.py 데이터 …` |
| 콘텐츠 | 무엇을 쓸지 고르고 글을 쓴다(확인한 것만) | `posts/` `notes/` → `넘김/` 으로 넘김 |
| 홍보 | 알릴 글·그림·영상·메일을 만들고, 올릴 묶음을 사람 앞에 놓는다 | `promo_out/` `cards/` `shorts/` `run.py 메일` |
서브에이전트는 세션이 잠깐 불러 쓰는 일꾼이다: `.claude/agents/` 에 넷이 들어 있다 — **조사**(`researcher`: 자료를 찾아 확인하고 출처와 함께 돌려줌) · **글초안**(`drafter`: 주어진 자료로 글 한 편) · **검사**(`checker`: 올리기 전 틀린 곳·깨진 곳·사진) · **데이터**(`data-keeper`: 현황·백업·주문표). 세션에게 「조사 서브에이전트에게 ○○를 맡겨」라고 하면 불러 쓴다.

## 3. 세션을 나눈다 (독자가 창을 연다)
「혼자 하던 일을 넷이 나눠 하게 해 보겠습니다.」
- **창을 더 연다**: 같은 폴더에서 Claude Code 를 창 셋 더 열고 한 줄씩 — `/역할 개발` · `/역할 콘텐츠` · `/역할 홍보`(이 창은 `/총괄`). 모드를 같게 맞추라고 알려 준다(다르면 세션끼리의 말이 받는 쪽에서 붙잡힌다 — 그럴 때는 `넘김/` 폴더의 파일로 넘긴다).
- **창 하나로**: 창을 못 열면 이 세션이 서브에이전트를 불러 같은 일을 한다.
그다음 일을 하나 흘려 보인다 — 「오늘 글 한 편」: 총괄이 콘텐츠에 넘김 → 콘텐츠가 **조사** 서브에이전트에게 자료를 맡기고 돌아온 것을 직접 열어 확인 → **글초안** 에게 초안을 맡기고 직접 읽어 고침 → `넘김/` 에 둠 → 개발이 **검사** 를 돌리고 올림 → 홍보가 알릴 글·그림을 준비 → 총괄이 한 장으로. 끝나면 누가 누구에게 무엇을 넘겼는지(`기록/` `넘김/`)를 독자에게 그대로 보인다.
짚어 줄 것 한 줄: 「서브에이전트가 돌려준 것은 그대로 믿지 않고 맡긴 세션이 직접 확인합니다.」

## 4. 되풀이해서 돌리기와 권한 (거버넌스)
- **세션 안에서 되풀이**: `/loop 30m 넘김 폴더에 새로 온 것이 있으면 처리해` 처럼 간격과 할 일을 준다. 창을 닫으면 멈춘다.
- **사람 없이 한 번**: 터미널에서 `claude -p "런북.md 를 읽고 오늘 한 바퀴 돌려" --allowedTools "Read,Edit,Bash"` — 예약 작업이 부르는 꼴이 이것이다. 물어볼 사람이 없으므로 무엇을 써도 되는지를 미리 정해 준다(정해 주지 않은 것은 거절된다).
- **컴퓨터를 꺼도 도는 예약**: `/schedule` 은 클라우드에서 정한 시각에 돌린다(요금제에 따라 쓸 수 있다). 이 PC 의 파일을 만지는 일은 5의 예약으로, 저장소만 있으면 되는 일은 이쪽으로.
- **무엇을 못 하게 막아 둘지**: `.claude/settings.json` 의 `permissions.deny` 에 규칙이 들어 있다 — 비밀 값 파일(`.env`·`mail.local.json`)은 읽지 못하게, 억지로 덮어쓰는 푸시와 통째로 지우는 명령은 못 하게. 독자에게 파일을 열어 네 줄을 보이고 하나를 직접 겪게 한다: 「mail.local.json 을 읽어 봐」 → 세션이 막혔다고 답하는 것을 본다. 규칙은 독자가 늘릴 수 있다(예: `"Bash(git push *)"` 를 넣으면 푸시를 아예 못 한다). 막힌 것을 다른 길로 돌아가지 않는다.
- **물어보고 하는 것**: 권한 모드가 기본(물어보는 모드)이면 세션은 명령을 돌리기 전에 사람에게 묻는다. 메일을 보내는 `--send` 는 여기에 더해 「보내」라는 말을 들은 뒤에만 부른다. 더 세게 걸고 싶으면 도구가 돌기 직전에 스크립트로 검사하는 훅(hooks)이 있다 — 스크립트가 2 로 끝나면 그 명령은 막힌다.
- **사람이 승인하는 자리는 정해져 있다**: 처음 공개하는 것, 바깥 채널에 올리는 것, 메일을 보내는 것, 돈과 계정에 관한 것. 나머지는 묻지 않고 돈다.

## 5. 날마다 저절로
`python run.py 자동 예약 07:00`(걸 명령만 보인다) → 독자가 「걸어 줘」 하면 `--예`(이 PC 의 예약 작업에 한 줄이 생긴다고 먼저 말한다). 끄기 `python run.py 자동 예약 끄기 --예`, 상태 `자동 예약 상태`.

## 6. 무엇을 쓸지 고르고 쓴다
소식을 모으는 사이트면 `python run.py 사이클`(모으기 → 묶기 → 대조 → 화면). 글 사이트면 콘텐츠 세션이 다음 글 세 개를 고른다(독자의 주제에서, **조사** 서브에이전트로 찾아볼 것을 맡김) → 한 편을 써서 싣고 `python run.py 올려`.

## 7. 메일을 자동으로
`python run.py 메일` — 오늘 올라간 것을 메일 한 통으로 만들어 **미리보기**만 한다. 보내려면 SMTP 설정이 있어야 한다: 「메일 서비스에서 SMTP 를 켜고 앱 비밀번호를 받아 `mail.local.json` 에 직접 넣어 주세요」(비밀번호는 독자가 넣고, 세션은 파일을 열어 보지 않는다. 넣을 칸은 `python mail.py` 가 알려 준다). 설정이 되면 독자 자신의 주소로 한 통: 독자가 「보내」 하면 `python run.py 메일 --send --to <독자의 주소>`. 받는 사람 목록에 남을 넣는 것은 그 사람이 받겠다고 한 때만.

## 8. 영상을 만들고 채널을 굴린다
`python shorts.py` — 글 한 편으로 세로 짧은 영상과 제목·설명 글이 나온다(ffmpeg 이 있을 때). 세션이 영상을 한 번 열어 길이·글자 잘림을 **검사** 하고 올릴 묶음(`shorts/<글>.mp4` + `.txt`)을 사람 앞에 놓는다. 올리는 것은 독자가 로그인한 채널에서 — 브라우저 확장이 있으면 세션이 올리는 화면까지 채우고 「게시」 앞에서 멈춘다.

## 9. 블로그와 SNS 로 알린다
`promo_out/<글>/블로그글.md`·알림 문구 세 길이, `cards/<글>_sq.png` 가 1에서 만들어져 있다. 독자가 블로그 글쓰기 화면을 열어 두면 확장으로 제목·본문을 채우고 「발행」 앞에서 멈춘다. 확장이 없으면 파일이 어디 있는지와 순서를 한 줄씩.

## 10. 자료를 관리한다
「쌓이는 것을 누가 지키는지 정합니다.」 `python run.py 데이터 현황`(글·상품·주문·올린 주소·마지막 백업) → `python run.py 데이터 백업` → 일부러 글 하나를 지우고 `python run.py 데이터 복구 --예` 로 돌아오는 것을 보인다. 가게가 있으면 `python run.py 데이터 주문표`(주문을 표로, `넘김/주문표.csv`)와 운영자 화면(`/admin`)의 입금 확인. 이 일은 **데이터** 서브에이전트에게 맡겨 아침마다 돌게 한다(5의 예약에 얹는다).

## 11. 방송 화면, 그리고 어긋났을 때
- `python run.py 자동 방송` — 그날 글을 차례로 띄우고 읽어 주는 화면. 송출은 사람이 시작한다.
- 어긋났을 때 세 가지만: 같은 실패가 두 번 이어지면 멈추고 기록에 남긴다 / 올린 것이 주소에서 안 보이면 다시 올리기 전에 주소부터 열어 본다 / 무엇을 고쳤든 `python run.py 되돌리기`, 자료는 `데이터 복구`.

## 맺는다
오늘 사람 없이 된 것, 독자가 승인한 것, 걸어 둔 예약, 상태창. 「여기까지가 튜토리얼입니다. 이제부터는 차례가 없습니다.」
