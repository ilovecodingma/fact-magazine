# 3장 — 운영팀을 세워 본다: 내가 없어도 돌고, 알려진다
먼저 `과외.md` 를 읽는다. **1·2장과 반대로 묻지 않고 끝까지 도는 것이 기본**이다. 세션은 일을 벌여 놓고 결과 한 장을 내민다. **이 장의 도착점: 「내가 출근해 있는 동안에도 글이 올라가고 알릴 글·그림·영상이 만들어진다고? 방송 화면까지?」** 튜토리얼은 여기서 끝난다 — 그 뒤는 독자가 알아서 굴린다.

출력마다 두 줄을 갈라 말한다: **사람 없이 된 것 / 여기서 사람이 로그인하면 이어지는 것.**

## 1. 사람 없이 한 바퀴 (세션이 혼자, 독자는 보기만)
「지금부터 제가 아무것도 묻지 않고 하루치 일을 끝까지 해 보겠습니다.」
`python run.py 자동 맛보기` — 소식 모으기 → 묶기 → 대조 → 화면 → 알릴 글(블로그 글·알림 문구) → 알릴 그림(카드) → 알릴 영상(세로 짧은 영상, ffmpeg 이 있을 때) → 점검. 끝나면 `넘김/자리비운동안.md` 를 읽어 주고, 만들어진 블로그 글·카드 그림·영상을 하나씩 열어 보인다.
(소식을 다루지 않는 사이트 — 글 사이트·게시판·장터·순위 — 는 화면·운영자 일·점검만 돈다. 알릴 것을 맛보려면 독자의 글 한 편으로 `python promo.py posts/<글>.md` 를 따로 돌려 보인다.)

## 2. 자리를 비워 본다
「2분 뒤에 저절로 돌게 해 두겠습니다. 창을 내려 두고 다른 일을 하다 오세요.」
`python run.py 자동 맛보기 --뒤 2` → 독자가 돌아와 「자리 비운 동안 뭐 했어?」 하면 `넘김/자리비운동안.md` 를 읽어 준다.

## 3. 운영팀을 세운다 — 세션을 여럿으로
「혼자 하던 일을 넷이 나눠 하게 해 보겠습니다.」 두 길 가운데 독자의 상황에 맞는 쪽으로:
- **창을 더 연다(권함)**: 같은 폴더에서 Claude Code 를 창 셋 더 열고 각 창에 한 줄씩 — `/역할 개발` · `/역할 콘텐츠` · `/역할 홍보`(이 창은 `/총괄`). 창 여는 것은 독자가 한다(`세팅.md`). 모드를 같게 맞추라고 알려 준다(다르면 세션끼리의 말이 붙잡힌다. 그럴 때는 `넘김/` 폴더의 파일로 넘긴다).
- **창 하나로**: 이 세션이 작은 에이전트를 불러 역할을 나눠 맡긴다(`역할/세션하나로.md`). 한 번에 한 역할씩.
그다음 일을 하나 흘려 보인다: 총괄 「오늘 글 한 편」 → 콘텐츠가 주제를 골라 `넘김/` 에 글을 둠 → 개발이 대조·찍기 → 홍보가 알릴 글·그림을 준비 → 총괄이 모아 독자에게 한 장으로. 누가 누구에게 무엇을 넘겼는지는 `기록/` 과 `넘김/` 에 남는다 — 끝나면 그 줄을 독자에게 보인다.

## 4. 날마다 저절로
「아침 7시마다 이 한 바퀴가 저절로 돌게 걸까요?」 → `python run.py 자동 예약 07:00`(걸 명령만 보인다) → 독자가 「걸어 줘」 하면 `--예` 를 붙여 건다(이 PC 의 예약 작업에 한 줄이 생긴다고 먼저 말한다). 끄는 법도 같이: `python run.py 자동 예약 끄기 --예`. 상태: `자동 예약 상태`.

## 5. 바깥으로 — 사람이 로그인하면 이어지는 것
준비물은 1에서 다 만들어져 있다. 여기부터는 독자의 계정이 필요하므로 하나씩, 독자가 하겠다는 것만.
- **블로그**: 독자가 블로그에 로그인해 글쓰기 화면을 열어 둔다 → 브라우저 확장(Claude in Chrome)이 연결돼 있으면 세션이 `promo_out/<글>/블로그글.md` 를 제목·본문에 채워 넣고 **「발행」 앞에서 멈춘다** → 독자가 보고 「올려」.
- **영상·카드**: `shorts/<글>.mp4` 와 `.txt`(제목·설명), `cards/<글>_sq.png` 를 같은 방식으로 올리는 화면까지 채우고 멈춘다.
- **사이트 다시 올리기**: 1장에서 한 번 올렸으면 「올려」 한마디로 세션이 찍고 올린다.
- 확장이 없거나 로그인하지 않겠다면: 파일이 어디 있는지와 올리는 순서를 한 줄씩 알려 주고 넘어간다.

## 6. 방송 화면까지
`python run.py 자동 방송` — 그날 글을 차례로 띄우고 소리 내어 읽는 방송 화면이 내 PC 에서 돈다. 실제 송출은 방송 프로그램으로 이 창을 잡아 로그인된 채널로 내보내야 하고, 시작은 사람이 한다.

## 7. 받아서 살핀다 (2장의 가게가 있을 때)
`python run.py 가게 상태` — 상품·주문·상품평 수를 읽어 주고, 들어온 주문은 독자가 운영자 화면(`/admin`)에서 「입금 확인·보냄」으로 넘긴다. 세션은 「처리 기다리는 주문이 몇 건」인지 아침 보고에 한 줄로 넣는다.

## 맺는다
오늘 사람 없이 된 것, 독자가 「올려」 한 것, 걸어 둔 예약. 「여기까지가 튜토리얼입니다. 이제부터는 차례가 없습니다 — 바꾸고 싶은 것, 시키고 싶은 것을 말하면 됩니다.」
