# 3장 — 운영·홍보: 혼자, 쉬는 시간마다 (자동이 기본)
먼저 `과외.md` 를 읽는다. **1·2장은 고르면서 가는 장이었고, 3장은 반대로 묻지 않고 도는 것이 기본**이다: 하루 한 바퀴·올릴 묶음·쉬는시간은 끝까지 돌고, 사람에게는 정할 것만 내민다. 휴대폰에서 이어 하는 것을 전제로 한다.

0. **세션 하나로 시작(기본)** — 탭 하나로 아래 1~4 를 그대로 돈다. 일을 나누고 싶을 때만 **팀 세팅(선택)**: 터미널 탭 넷(`세팅.md`) 탭1 `/총괄`, 탭2 `/역할 개발`, 탭3 `/역할 콘텐츠`, 탭4 `/역할 홍보`(shift+tab 으로 모드를 같게, 대화가 안 되면 `넘김/` 폴더의 요청 파일). 역할 세션은 자기 일을 하며 「지금 무엇을 왜 하는지」를 한 줄로 말한다.
1. `/사이클` — 하루 한 바퀴(수집 → 묶기 → 대조 → 화면 → 홍보 문구 → 카드 → 점검). 단계마다 건수·만든 곳을 말하고, 올리기·메일은 사람 승인 전에는 하지 않는다. 뉴스 기능이 꺼진 사이트는 수집·묶기·대조·홍보·카드 단계를 「건너뜁니다」로 알린다. `--shots 폴더` 면 단계 결과 화면이 저장된다.
2. `python run.py 쉬는시간` — 지금 사람이 볼 것만: 올릴 묶음, 정해야 하는 것, 어긋난 것, 어제 대비 바뀐 것. 백엔드를 켠 경우 운영자 화면(`/admin/`: 오늘 방문·새 댓글·문의·소식 받기 수)을, 끈 경우 이 출력과 상태 쪽이 그 자리를 대신한다. 아침·점심·저녁 세 번의 짧은 걸음으로 돌린다.
3. 「올려」 한마디로 넘어갈 수 있게 올릴 묶음을 채널별로 정리하고, 사람이 승인한 것만 올린다(올리기·로그인은 사람 몫).
4. 한 달 뒤: `python run.py 만듦새`·상태 점검·`묶음 키워드`로 다음 달 할 일을 정한다. 내놓기는 `python run.py 내놓기`(24시간 PC / 클라우드).
끝에 독자가 「오늘 사람이 정해야 했던 것」을 직접 말해 본다.
