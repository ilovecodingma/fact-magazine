# 1장 — 80% 만들어진 서비스를 내 것으로 (한 걸음 하고 멈춤)
먼저 `과외.md` 를 읽고 그 방식(상담 → 고름 → 적용 → 생각 묻기 → 멈춤)으로 진행한다. **세션은 고르지 않고, 독자가 고른다.** 올리기·로그인·결제는 하지 않는다. 이 장은 고르면서 가는 장이라 「다 해 줘」는 한 번 확인한 뒤에만(`전부 --예`).
시작할 때 `독자.json`·`내_서비스.md`·`생각.md`·`진도.json` 을 읽고 있으면 「지난번에 ○○까지 정하셨습니다」로 이어 간다.

## 0. 열고 한 바퀴 (10분)
- `python run.py 열기` — 80% 완성된 서비스(파이어족 뉴스 바탕)를 내 PC 에서 연다. **방문자의 길**(첫 화면 → 글 → 관련 글 → 도구 → 소식 받기)과 **운영자의 하루**(소식 모으기 → 확인 노트 → 올릴 묶음 → 쉬는시간)를 걷는다.
- 독자에게 한 번만: 컴퓨터로 해 본 것·만들고 싶은 것·하루 시간 → `python run.py 독자 설정 …`.
- 투박한 지금 모습과 참고 사이트를 나란히 보인다(`python run.py 비교`, `참고`). 첫 물음: 「어디가 아직 어설퍼 보이나요? 어떤 사이트처럼 보이고 싶나요?」 → 답을 되말하고 `내서비스 칸` 에 적는다(닮고 싶은 곳).
- 걸음마다 `다듬기 N`(안 없이) → 미리보기 → 독자가 고름 → `고름` 기록 → `다듬기 N --안 …`. `다음` 은 앞 걸음을 골랐을 때만 열린다.

## 구획 (서비스의 물음 순서 — 번호는 `다듬기.json` 그대로)
1. **누가 오는가** — 걸음 0 이름·한 줄 소개, 걸음 1 글자(누가, 어디서 보나)
2. **무엇을 먼저 보이나** — 걸음 4 첫 화면 짜임, 걸음 5 그림
3. **믿게 하는 것** — 걸음 3 제호와 메뉴, 걸음 2 색, 걸음 7 글 쪽, 걸음 8 푸터·믿을 근거
4. **만드는 방식 ①** — `python run.py 방식 프런트`: 미리 찍어 두는 화면 / 누르면 바뀌는 화면 / 앱처럼 쓰는 화면. 방문자가 주로 무엇을 하는가에 비추어 경우를 말하고 독자가 고른다.
5. **다시 오게 하는 것** — 걸음 6 오늘의 숫자·호 표지·소식 받기, 걸음 9 휴대폰 아래 메뉴
6. **만드는 방식 ②** — `python run.py 방식 백엔드`: 받지 않는다(백엔드 없음) / 내 PC 의 도커 서버로 받는다 / 바깥 서비스에 맡긴다(준비 중). 「받으면 다시 올 까닭이 생기지만 날마다 볼 일이 늡니다. 받을까요?」
7. **운영자가 아는 것** — (백엔드 (나)를 골랐을 때만) 도커 갈림: `python run.py 도커`(PC 를 읽고 경우를 말하고 독자가 고르면 공식 사이트로) → `python run.py 서버` → 댓글·방문 통계(무엇을 알고 싶은가)·문의·소식 받기(주소를 맡는다는 것)·운영자 화면 `/admin/`. 도커를 못 쓰거나 안 쓰면 (가)로 끝까지 간다(백엔드 걸음만 건너뜀으로 기록).
8. **벌 자리** — `monetize` 키트(광고 칸·제휴 링크 고지·후원·소식 받기, 가입·심사는 사람 몫).
9. **내놓기 갈림** — `python run.py 내놓기`: 「이 PC 를 24시간 켜 둘 수 있나요?」(올리기.md).
10. **끝** — `python run.py 고른것 --shots`, 출발 모습과 지금 모습 나란히, 켜 둔 것만 남은 내 사이트가 열려 있게(`python run.py 지금`·`열기`).

## 둘러보기(기능 서랍)
80% 안에 이미 든 기능은 `python run.py 지도`가 아니라 `묶음`·`키트`로 필요할 때 꺼내 본다(`python run.py 묶음`, `키트 계산기`, `켜기`/`끄기`). 기능을 늘리는 길은 독자가 「이것도 붙이고 싶다」고 할 때만.

## 마무리
「오늘 배운 것 세 줄 + 헷갈려 한 것 + 다음에 할 것」을 말하고 진도에 적은 뒤 「2장은 이 사이트를 다른 종류로 바꿔 봅니다」를 안내한다.
