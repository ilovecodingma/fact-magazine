토마토 달걀볶음

재료

  • 토마토 2개
  • 달걀 3개
  • 대파 1/2대
  • 소금 1/3작은술
  • 설탕 1작은술
  • 식용유 2큰술

만드는 순서

  1. 토마토를 한입 크기로 썬다.
  2. 달걀을 풀어 소금을 넣고 팬에 부드럽게 스크램블한다.
  3. 달걀을 접시에 덜어 둔다.
  4. 같은 팬에 대파와 토마토를 넣고 볶는다.
  5. 설탕을 넣고 달걀을 다시 넣어 가볍게 섞는다.
