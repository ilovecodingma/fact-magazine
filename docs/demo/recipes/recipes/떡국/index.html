요리법

떡국

재료

  • 떡국 떡 2컵
  • 소고기 100g
  • 달걀 1개
  • 대파 1대
  • 국간장 1큰술
  • 다진 마늘 1작은술
  • 물 6컵

만드는 순서

  1. 떡을 찬물에 20분 불린다.
  2. 냄비에 고기를 볶고 물을 부어 20분 끓인다.
  3. 국간장과 마늘로 간한다.
  4. 떡을 넣고 떠오를 때까지 끓인다.
  5. 달걀을 풀어 넣고 대파를 올린다.
