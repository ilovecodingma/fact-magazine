요리법

메밀국수 냉국

재료

  • 메밀국수 2인분
  • 다시마 육수 2컵
  • 간장 3큰술
  • 설탕 1큰술
  • 무 100g
  • 대파 1/2대
  • 김 약간

만드는 순서

  1. 육수에 간장, 설탕을 넣고 차갑게 식힌다.
  2. 무는 갈고 대파는 송송 썬다.
  3. 메밀국수를 삶아 찬물에 여러 번 헹군다.
  4. 그릇에 면을 담고 육수를 붓는다.
  5. 무, 대파, 김가루를 올리고 얼음을 띄운다.
