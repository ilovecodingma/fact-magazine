요리법

콩나물무침

재료

  • 콩나물 300g
  • 대파 1/2대
  • 다진 마늘 1/2작은술
  • 소금 1/2작은술
  • 참기름 1큰술
  • 통깨 약간

만드는 순서

  1. 콩나물을 씻어 냄비에 넣고 물 반 컵을 붓는다.
  2. 뚜껑을 덮고 5분 삶는다.
  3. 건져 찬물에 식히고 물기를 뺀다.
  4. 대파, 마늘, 소금, 참기름을 넣어 무친다.
  5. 통깨를 뿌린다.
