만드는 순서

  1. 두부를 도톰하게 썰어 물기를 닦는다.
  2. 팬에 기름을 두르고 앞뒤로 노릇하게 부친다.
  3. 간장, 고춧가루, 마늘, 설탕, 물을 섞어 양념을 만든다.
  4. 두부 위에 양념을 올리고 중약불에서 조린다.
  5. 국물이 자작해지면 대파를 올린다.
