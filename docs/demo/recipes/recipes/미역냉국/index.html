  • 식초 3큰술
  • 설탕 1큰술

만드는 순서

  1. 미역을 불려 헹군 뒤 먹기 좋게 자른다.

  3. 찬물에 식초, 설탕, 국간장으로 간한다.
  4. 미역과 채소를 넣고 섞는다.
  5. 얼음을 띄워 시원하게 낸다.
