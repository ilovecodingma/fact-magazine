감자전

재료

  • 감자 3개
  • 소금 1/3작은술
  • 식용유 4큰술
  • 청양고추 1개
  • 간장 1큰술
  • 식초 1/2큰술

만드는 순서

  1. 감자를 강판에 갈아 체에 받친다.
  2. 물은 가만히 두어 가라앉은 앙금을 건져 반죽에 섞는다.
  3. 소금을 넣고 섞는다.
  4. 팬에 기름을 넉넉히 두르고 반죽을 얇게 펴 노릇하게 부친다.
  5. 간장, 식초, 다진 고추로 양념장을 곁들인다.
