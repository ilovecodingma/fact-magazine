콩나물국

재료

  • 콩나물 200g
  • 대파 1/2대
  • 다진 마늘 1작은술
  • 국간장 1큰술
  • 멸치 육수 4컵
  • 소금 약간

만드는 순서

  1. 콩나물을 씻어 물기를 뺀다.
  2. 육수를 끓이다가 콩나물을 넣고 뚜껑을 덮는다.
  3. 5분 끓인 뒤 뚜껑을 열지 않은 채 한 번 더 끓인다.
  4. 마늘과 국간장을 넣는다.
  5. 대파를 넣고 소금으로 간한다.
