두부김치

재료

  • 두부 1모
  • 김치 1컵
  • 돼지고기 앞다리살 100g
  • 참기름 1큰술
  • 식용유 1큰술
  • 통깨 약간

만드는 순서

  1. 두부를 큼직하게 썰어 끓는 물에 데친다.
  2. 팬에 식용유를 두르고 고기를 볶는다.
  3. 김치를 넣고 3분 더 볶은 뒤 참기름을 넣는다.
  4. 접시에 두부를 두르고 볶음 김치를 올린다.
  5. 통깨를 뿌려 낸다.
