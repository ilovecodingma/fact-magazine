요리법

김치찌개

재료

  • 잘 익은 김치 2컵
  • 돼지고기 목살 150g
  • 두부 1/2모
  • 대파 1대
  • 양파 1/2개
  • 고춧가루 1큰술
  • 물 3컵

만드는 순서

  1. 김치와 돼지고기를 한입 크기로 썬다.
  2. 냄비에 고기와 김치를 넣고 중불에서 3분 볶는다.
  3. 물과 고춧가루를 넣고 끓어오르면 중약불로 줄여 15분 끓인다.
  4. 양파와 두부를 넣고 5분 더 끓인다.
  5. 대파를 넣고 간을 맞춰 마무리한다.
