요리법

김치볶음밥

재료

  • 밥 2공기
  • 김치 1컵
  • 양파 1/2개
  • 햄 또는 돼지고기 80g
  • 식용유 2큰술
  • 참기름 1큰술
  • 달걀 2개

만드는 순서

  1. 김치, 양파, 고기를 잘게 썬다.
  2. 기름을 두르고 고기와 양파를 볶는다.
  3. 김치를 넣고 3분 더 볶는다.
  4. 밥을 넣고 센 불에서 볶은 뒤 참기름을 두른다.
  5. 달걀 프라이를 올려 낸다.
