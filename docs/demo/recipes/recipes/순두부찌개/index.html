순두부찌개

재료

  • 순두부 1봉
  • 애호박 1/3개
  • 양파 1/3개
  • 달걀 1개
  • 고춧가루 1큰술
  • 다진 마늘 1작은술
  • 대파 1/2대
  • 식용유 1큰술

만드는 순서

  1. 냄비에 식용유, 고춧가루, 대파를 넣고 약불에 볶아 향을 낸다.
  2. 물 1컵을 부어 끓인다.
  3. 애호박과 양파를 넣고 3분 끓인다.
  4. 순두부를 크게 떠 넣고 마늘, 소금으로 간한다.
  5. 5분 끓인 뒤 달걀을 깨 넣는다.
