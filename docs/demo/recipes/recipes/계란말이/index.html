만드는 순서

  1. 당근과 대파를 아주 잘게 다진다.
  2. 달걀을 풀고 소금, 채소를 섞는다.
  3. 약불로 달군 팬에 기름을 얇게 두르고 달걀물 1/3을 붓는다.
  4. 반쯤 익으면 돌돌 말아 한쪽으로 민다.
  5. 남은 달걀물을 두 번 나누어 같은 방식으로 말아 식혀 썬다.
