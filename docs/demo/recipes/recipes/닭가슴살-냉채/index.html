만드는 순서

  1. 닭가슴살을 15분 삶아 식힌 뒤 찢는다.

  3. 겨자, 식초, 설탕, 간장, 물을 섞어 소스를 만든다.
  4. 접시에 채소와 닭가슴살을 올린다.
  5. 먹기 직전에 소스를 뿌린다.
