재료

  • 사각 어묵 4장
  • 무 200g
  • 대파 1대
  • 다시마 1장
  • 멸치 5마리
  • 국간장 1큰술
  • 물 5컵

만드는 순서

  1. 무를 도톰하게 썬다.
  2. 물에 무, 다시마, 멸치를 넣고 15분 끓여 건져낸다.
  3. 어묵을 한입 크기로 썰어 넣는다.
  4. 국간장을 넣고 5분 끓인다.
  5. 대파를 넣고 간을 맞춘다.
