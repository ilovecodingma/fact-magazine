매체마다 다르게 전한 점

  • 매체 제목의 숫자(2개월 연장, 휘발유 15%, 경유 25%)는 서로 같다.

아직 확인 안 된 것

  • 연장 기간과 끝나는 날짜.
  • 휘발유 15%, 경유 25% 인하율.
  • 11일 오전 재정경제부 누리집 보도자료 목록 첫 쪽과 정책브리핑 보도자료 목록(11월 10~11일)에서 해당 자료를 찾지 못했다.
