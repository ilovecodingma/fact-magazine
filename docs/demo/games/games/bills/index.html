청구서 피하기

세 줄로 떨어지는 「청구서」를 피하고 「절약」 동전을 모으는 한 손 게임. 갈수록 빨라집니다.

  1. 화면 왼쪽을 누르면 한 줄 왼쪽으로, 오른쪽을 누르면 한 줄 오른쪽으로 갑니다(PC는 ← →).
  2. 청구서에 닿으면 목숨이 하나 줄고, 목숨은 3개입니다.
  3. 절약 동전을 이어서 먹으면 점수가 더 붙습니다.
