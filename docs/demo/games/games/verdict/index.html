확인 도장 판정

소식과 출처를 보고 「확인됨」「아직 확인 안 됨」 도장을 빨리 찍는 한 손 반응 게임. 이 사이트가 소식을 확인하는 기준을 게임으로 익힙니다.

  1. 출처가 공식 기관 자료이면 화면 왼쪽(확인됨), 지인·익명·캡처·「카더라」이면 오른쪽(아직 확인 안 됨)을 누릅니다(PC는 ← →).
  2. 45초 동안 최대한 많이 맞히세요. 3번 틀리면 끝나고, 연속으로 맞히면 점수가 더 붙습니다.
  3. 소식은 모두 지어낸 예시(가상의 시·기관)라 실제 사실과 무관합니다.
