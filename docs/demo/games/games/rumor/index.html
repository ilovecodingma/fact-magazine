뜬소문 막기

캐릭터가 자동으로 공격하고, 몰려오는 적을 피해 움직이며 경험치로 무기를 강화해 오래 버티는 자동 공격 생존 게임. 여기서는 확인 도장으로 뜬소문을 막습니다.

  1. 화면을 끌어서 움직입니다(PC는 방향키·WASD). 도장은 가까운 뜬소문에게 저절로 날아갑니다.
  2. 뜬소문이 남기는 파란 증거 조각을 모으면 레벨이 오르고, 강화(8종) 세 가지 중 하나를 고릅니다(PC는 1·2·3).
  3. 5분을 버티면 정정 보도가 나갑니다. 체력이 다하면 그때까지 버틴 시간이 기록이 됩니다.
