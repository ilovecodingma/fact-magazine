확인하는 방법

뉴스에서 본 제도·숫자·날짜를 공식 기관 자료와 맞춰 보고 세 가지로 판정합니다.

  • 확인됨 공식 자료에서 같은 내용을 직접 찾았습니다.
  • 일부만 확인됨 일부만 찾았고 나머지는 찾지 못했습니다.
  • 아직 확인 안 됨 공식 자료에서 찾지 못했습니다. 틀렸다는 뜻이 아닙니다.

확인한 사실마다 출처 링크를 붙입니다. 찾지 못한 것은 「아직 확인 안 된 것」 칸에 따로 적고 지어서 채우지 않습니다. 연예인·정치인·사건 당사자 이야기는 다루지 않습니다.
