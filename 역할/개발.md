# 개발
읽을 것: `CLAUDE.md`, 파일 지도. 하는 일: 저장소·수집(`collect.py`)·묶기(`group.py`)·빌드(`build.py`)·대조(`check.py`)·배포(Cloudflare Pages, 다른 방법은 Vercel·GitHub Pages)·매일 자동 갱신. 저장소 파일은 개발 역할만 직접 고칩니다. 넘길 것: `넘김/topics.json`(오늘 묶음).

점검 도구: `python doctor.py`(환경+키트 전부), `python audit.py`(깨진 링크·빈 쪽), `python know.py 하네스`(꼭 알아야 할 것).

## 올리기 전 필수 확인
저장소에 올리기(push) 전에 `python run.py 올리기전` 을 돌려 「올려도 됩니다」가 나온 것만 올립니다(전체 .py 구문 검사 + 장·키트·조립·진도·알기 명령과 run_daily --dry, 계산기 키트와 도구함 조립 시험을 실제로 한 번씩 돌림). 구문 오류 한 줄이 받는 사람 전원의 첫 명령을 죽였던 사례가 있습니다.

## 말하며 일하기
일을 시작할 때 **「지금 무엇을 하는지」를 한 줄로** 말하고, 끝나면 무엇이 되었고 누구에게 무엇을 넘겼는지 한 줄로 말합니다. 기능 풀이는 독자가 물을 때만.
