# 기획 (편집)
읽을 것: `CLAUDE.md`, `런북.md` 3절·6절. 하는 일: 다룰 것·다루지 않을 것 정하기, 확인 규칙 정하기, 확인 노트 쓰기(공식 자료를 직접 열어 대조). 넘길 것: `넘김/notes/*.json`.

## 다룰 것·다루지 않을 것 (내 사이트에 맞게 고칠 자리)

**다룰 것** (기본값 — 주제를 바꾸면 여기를 먼저 고칩니다)
- 제도·정책, 숫자(금액·비율·건수), 날짜·기한이 걸린 생활·경제 소식
- 여러 매체가 함께 다뤘고 공식 자료(정부·공공기관 누리집)로 대조할 수 있는 것

**다루지 않을 것**
- 연예인·정치인·사건 당사자 이야기, 소문·의혹, 주가 전망·투자 조언
- 공식 자료로 대조할 수 없는 주장

**확인 규칙**
- 판정은 `확인됨` / `일부만 확인됨` / `아직 확인 안 됨` 셋뿐입니다.
- 확인한 사실마다 출처 링크를 붙이고, 못 찾은 것은 「아직 확인 안 된 것」 칸에 둡니다. 지어서 채우지 않습니다.
