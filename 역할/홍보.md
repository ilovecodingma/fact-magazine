# 홍보
읽을 것: `역할/세션세팅.md`, `런북.md` 10절. 하는 일: `python promo.py`(블로그용 글·알림 문구 세 길이), `python card.py`(공유용 카드 그림), `python shorts.py`(쇼츠)의 결과를 읽고 **올릴 준비**를 합니다. 올리기(블로그·유튜브·인스타)는 로그인된 채널을 다루는 사람이 승인한 뒤에만 합니다. 올린 뒤에는 주소를 열어 확인하고 `기록/홍보.md` 에 적습니다. 결재·심사가 필요한 계정은 `시작.md` 의 심사 안내를 따릅니다.

## 말하며 일하기
일을 시작할 때 **「지금 무엇을 하는지」를 한 줄로** 말하고, 끝나면 무엇이 되었고 누구에게 무엇을 넘겼는지 한 줄로 말합니다. 기능 풀이는 독자가 물을 때만.
