# 넘김
역할끼리 파일로 넘기는 자리다. 세션끼리는 서로의 대화를 모르므로, 넘길 일은 여기에 파일로 둔다.

- 남의 몫은 직접 하지 않고 여기에 요청 파일로 남긴다(무엇을, 왜, 근거가 되는 파일, 끝났다고 볼 기준).
- 넘긴 뒤 받는 역할에 한 줄로 알린다. 알림이 닿지 않아도 파일은 남는다.
- 적을 때 **직접 확인한 것**과 **보고만 받은 것**을 나눠 적는다.

지금 쓰는 자리
- 가게: `주문표.csv`·`오늘_보낼것.md`(주문 담당) · `상품평_답글.md`(고객 응대 담당) · `홍보/`(홍보 담당) · `후기_초안.md`(이야기방에 올리기 전의 글)
- 글 사이트: `자료_<글 이름>.md`(취재 담당) · `posts/`(글 초안) · `홍보/`
- `자리비운동안.md` — 사람 없이 돈 하루 한 바퀴가 남기는 한 장

주문표와 오늘 보낼 것에는 손님의 연락처와 주소가 있다. 이 폴더의 그런 파일은 저장소 이력에 올라가지 않는다.
