# 한 줄로 내 서비스를 만들고 굴리는 실습 저장소

책 『가난한 박과장과 퇴근후 나의 서비스팀 관리하기』의 실습 저장소입니다. Claude Code 에 **한 줄**을 넣으면 에이전트가 사이트를 만들어 남에게 보여 줄 주소까지 냅니다. 독자는 명령을 외우지 않습니다 — 하고 싶은 것을 한 줄로 말하면 에이전트가 이끕니다.

## 시작하는 한 줄

(Claude Code 설치부터 처음이면 먼저 `시작_안내.md` 를 보세요.)

빈 폴더에서 Claude Code 를 켜고 이 한 줄만 넣습니다(미리 깔아 둘 것은 Claude Code 하나).

```
이 저장소 주소는 https://github.com/ilovecodingma/fact-magazine 야. 시작.md 를 읽고 <만들고 싶은 것> 사이트를 만들어 줘.
```

예) `… 시작.md 를 읽고 처음 캠핑 가는 사람을 위한 사이트를 만들어 줘.` — 만들고 싶은 것을 적지 않아도 됩니다.
이 한 줄 뒤에는 더 묻지 않고, 이름·색·글 여섯 편·사진을 채워 공개 주소가 나올 때까지 에이전트가 혼자 갑니다(5~8분).

## 세 장

| 장 | 독자가 넣는 말 | 나오는 것 |
|---|---|---|
| 1장 글 사이트 | 위의 한 줄 (저장소를 이미 받았으면 `1장을 진행해 보자`) | 글 읽는 사이트와 공개 주소(로그인 없이 60분, 가입하면 사라지지 않는 주소) |
| 2장 가게 | `2장을 진행해 보자. ○○ 가게를 만들어 줘` | 상품·장바구니·주문(무통장 입금)·상품평·찜·쿠폰·운영자 화면이 있는 가게와 바깥 주소, 휴대폰 앱(약 7분) |
| 3장 운영팀 | `3장을 진행해 보자` | 사람 없이 도는 하루 한 바퀴, 역할을 나눈 운영팀, 날마다 저절로 도는 예약 |

## 그 뒤에 바로 받는 말

`이름을 ○○로 바꿔 줘` · `되돌려 줘` · `올려 줘` · `이걸 요리법 모음으로 바꿔 줘` · `동네 맛집 묶음을 하나 더 붙여 줘` · `상품평을 떼 줘` · `주문 목록을 표로 뽑아 줘` · `데이터 백업해 줘` · `날마다 아침 8시에 돌려 줘` · `지금 어디까지 했어?` · `이어서 하자` · `토큰 발급해 줘` · `운영 기록을 받아 줘`

무엇을 바꿔도 `되돌려 줘` 한마디로 돌아옵니다.

## 사람 몫으로 남겨 둔 것

- 로그인·가입·결제·본인 인증, 바깥 채널에 글 올리기, 메일 보내기
- 가게의 운영자 비밀번호와 입금 계좌 — 에이전트에게 말하지 않고 운영자 화면에 직접 넣습니다(에이전트의 읽기 도구는 그 파일을 열지 못하게 막아 두었고, 에이전트는 열지 않도록 지침으로도 정해져 있습니다. 명령으로 읽는 길은 모두 막을 수는 없습니다)
- 윈도우 관리자 승인 창의 「예」

## 무엇으로 되어 있나

- 글 사이트: 파이썬 기본 기능만으로 찍는 정적 사이트. 올리기는 Vercel.
- 가게: 화면 Next.js, 서버 파이썬 기본 기능 + sqlite. 결제 없음(무통장 입금). 바깥 주소는 Cloudflare 의 통로 프로그램.
- 사진: 누구나 조건 없이 쓸 수 있게 풀린 것(CC0·퍼블릭 도메인)만 받아 사이트 안에 넣습니다.
- 에이전트가 읽는 지침: `CLAUDE.md`(전체 규칙) · `시작.md`(처음 받았을 때) · `과외.md`(이끄는 방식) · `코스/1장.md`~`3장.md` · `역할/`(운영팀의 자리).

학습 사이트(진도에 맞는 보기와 저자 팀의 운영 기록): https://sungprofile.cloud/park/
