# 조립 예시 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> python demo.py 로 demos/demos.json 의 조합 예시들을 각각 따로 찍어 /demo/ 아래에 올려 줘.

- **넣는 것 → 나오는 것**: 조합 목록(demos.json) → 조합마다 따로 찍은 사이트(/demo/이름/) + 목록 쪽
- **2분 안에 보는 결과**: /demo/ 에서 조합마다 다른 이름·메뉴의 사이트가 열립니다
- **켜기**: `python mix.py --add demo` 후 `python build.py` 그리고 `python demo.py`
- **서버**: 불필요
