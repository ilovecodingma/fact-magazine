# 조립 예시 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
조합 목록(demos.json) → 조합마다 따로 찍은 사이트(/demo/이름/) + 목록 쪽. /demo/ 에서 조합마다 다른 이름·메뉴의 사이트가 열립니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 조립 예시는 demos/demos.json 의 조합마다 이름·소개·켠 키트가 다른 사이트를 따로 찍은 것입니다. 같은 하네스로 다른 종류의 사이트를 만든다는 것을 보여 줍니다.
- 본 사이트를 빌드(build.py)한 뒤 python demo.py 를 돌려야 /demo/ 아래에 예시가 생깁니다. 빌드만 하면 메뉴의 「조립 예시」는 아직 빈 쪽입니다.
- 예시 사이트는 본 사이트와 내용이 겹치므로 검색에 나가지 않게(noindex) 만듭니다.

## ③ 한 번 해 보기
python build.py → python demo.py 를 돌린 뒤 /demo/ 에서 조합마다 다른 이름·메뉴의 사이트를 열어 봅니다. 하나만 보려면 python demo.py --only games --out 임시폴더 를 씁니다.

## ④ 바꿔 보기
demos/demos.json 의 한 조합에서 name(사이트 이름)을 바꾸고 python demo.py --only games --out 임시폴더 를 돌려, 찍힌 사이트 이름이 바뀌는지 보세요(끝나면 되돌리세요).
