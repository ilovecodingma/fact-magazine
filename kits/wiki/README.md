# 위키 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 위키를 켜 줘. kits/wiki/data 에 문서를 마크다운으로 두고 [[문서이름]] 으로 서로 링크하면 /wiki/ 에 문서와 「이 문서를 가리키는 문서」가 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 마크다운 문서(문서끼리 [[링크]]) → 위키 쪽 + 목록 + 되돌아보기
- **2분 안에 보는 결과**: /wiki/ 에서 문서를 열면 [[링크]] 가 눌리고 아래에 되돌아보기가 있습니다
- **예시 자료가 이미 들어 있습니다**: `kits/wiki/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add wiki`(지금 켜진 것에 더하기) 또는 `python mix.py wiki`(이것만) 후 `python build.py`
- **서버**: 불필요
