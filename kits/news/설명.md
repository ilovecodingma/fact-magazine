# 뉴스 수집·묶기 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
여러 매체의 뉴스 제목을 모아 묶고, 그 가운데 숫자·날짜가 걸린 소식을 공식 자료와 맞춰 본 「확인 노트」로 보여 주는 첫 화면입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 확인 노트의 판정은 「확인됨 / 일부만 확인됨 / 아직 확인 안 됨」 셋뿐이고, 못 찾은 것은 지어서 채우지 않는다 — 공식 자료에서 직접 찾은 것만 사실로 적는다는 규칙이기 때문입니다.
- 노트의 사실 문장마다 출처 주소가 있고, check.py 가 숫자·날짜 글자가 출처에 있는지 다시 대조한다 — 뉴스와 공식 자료의 숫자가 어긋나는 일을 잡기 위해서입니다.
- 이 대조는 느슨하다 — 같은 숫자가 다른 글에 있어도 통과할 수 있고, 뜻은 사람이 읽어야 한다 — 글자 포함 여부만 보기 때문입니다.

## ③ 한 번 해 보기
첫 화면의 큰 글 하나와 오른쪽 작은 글들에 「확인됨 / 일부만 확인됨 / 아직 확인 안 됨」 딱지가 붙어 있습니다. 큰 글을 누르면 확인한 사실과 출처가 나옵니다. 화면 시험은 `python selftest.py news --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
notes/ 의 확인 노트 하나에서 summary 한 줄을 고쳐 python build.py 를 다시 돌린 뒤 첫 화면 큰 글에 바뀐 문장이 뜨는지 보세요.
