# 연재 소설 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> novels 폴더에 작품 소개와 1~3화를 넣고 빌드해서 회차 이동과 글자 크기 조절이 되는지 확인해 줘.

- **넣는 것 → 나오는 것**: 소개·회차 마크다운 → 작품 쪽·회차 목록·이전/다음 화·글자 크기
- **2분 안에 보는 결과**: /novel/ 에서 1화를 읽고 다음 화로 갑니다
- **파일 위치·붙는 곳**: novels/ · 메뉴 「연재」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py novel` 후 `python build.py`
