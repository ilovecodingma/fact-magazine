# 연재 소설 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
소개 파일과 회차 파일(01.md, 02.md …)을 두면 작품 쪽, 회차 목록, 이전·다음 화 이동, 글자 크기 조절이 만들어지는 연재 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 작품은 novels/<작품폴더>/ 안에 소개.md 와 01.md, 02.md … 로 둔다 — 소개 파일은 작품 쪽에, 번호 파일은 회차 목록에 쓰이기 때문입니다.
- 회차 순서는 파일 이름의 숫자가 정한다(01, 02, 03) — 빌드가 파일 이름을 순서대로 읽어 이전·다음 화를 이어 주기 때문입니다.
- 글자 크기는 읽는 사람의 브라우저에 저장된다(14~26px 사이) — 버튼이 브라우저 저장소(localStorage)에 크기를 적어 두기 때문입니다.

## ③ 한 번 해 보기
/novel/ 에서 작품을 눌러 1화를 읽고, 「가+」 로 글자를 키우고, 「다음 화」 로 2화에 갑니다. 화면 시험은 `python selftest.py novel --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
novels/ 의 작품 폴더에 04.md 를 만들어 맨 위를 「# 4화. 내 제목」으로 쓰고 python build.py 를 돌려 회차 목록에 4화가 생기는지 보세요.
