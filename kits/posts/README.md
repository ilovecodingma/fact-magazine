# 글 올리기 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> posts 폴더에 이 글을 올려 줘(제목은 맨 위 # 한 줄). 빌드해서 /post/ 목록과 글 쪽이 열리는지 확인해 줘.

- **넣는 것 → 나오는 것**: 마크다운 글 → /post/ 목록과 글 쪽
- **2분 안에 보는 결과**: /post/ 에서 글이 열립니다
- **파일 위치·붙는 곳**: posts/ · 메뉴 「글」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py posts` 후 `python build.py`
