# 글 올리기 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
마크다운(# 제목, 문단처럼 간단한 기호로 쓰는 글 형식) 파일을 올리면 글 목록과 글 쪽이 만들어지는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 글은 posts/ 폴더의 마크다운 파일이고, 맨 위 `# ` 한 줄이 제목이다 — 빌드가 첫 줄을 제목으로 읽어 목록과 쪽 이름을 만들기 때문입니다.
- 파일 이름이 곧 주소다(isa-tax-free-limit.md → /post/isa-tax-free-limit/) — 주소는 파일 이름에서 그대로 만들어지기 때문입니다.
- 글을 더하거나 고친 뒤에는 python build.py 를 다시 돌려야 화면에 나온다 — 정적 사이트는 빌드 때 쪽을 한꺼번에 찍어 두는 방식이기 때문입니다.

## ③ 한 번 해 보기
/post/ 에 글 카드가 나오고, 누르면 제목과 본문이 열립니다. 화면 시험은 `python selftest.py posts --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
posts/ 폴더에 새 파일(예: 내첫글.md)을 만들어 맨 위 줄을 「# 내 첫 글」로 쓰고 python build.py 를 돌려 /post/ 목록에 뜨는지 보세요.
