# 퍼가기 위젯 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 퍼가기 위젯을 켜 줘. /widget/ 에 내 블로그에 붙일 한 줄 코드가 나오고 /embed/ 에 최근 노트 목록이 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 최근 노트 → 다른 사이트에 붙이는 작은 목록(iframe 한 줄)
- **2분 안에 보는 결과**: /widget/ 의 코드를 복사해 다른 쪽에 붙이면 목록이 보입니다
- **예시 자료가 이미 들어 있습니다**: `kits/widget/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add widget`(지금 켜진 것에 더하기) 또는 `python mix.py widget`(이것만) 후 `python build.py`
- **서버**: 불필요
