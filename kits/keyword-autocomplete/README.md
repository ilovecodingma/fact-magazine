# 하네스 1. 자동완성으로 후보 모으기

이렇게 입력하세요: `python -X utf8 run.py seeds.txt 결과.tsv`

- 넣는 것: seeds.txt (한 줄에 낱말 하나. 바꿔도 됨)
- 나오는 것: 결과.tsv (한 줄에 「검색어 탭 시드」) — 검색창 자동완성으로 뜨는 말
- 2분 안에 보는 결과: 결과.tsv 를 열어 어떤 말이 자주 따라 붙는지 본다(「신청」「조건」「언제」…)
- 로그인·계정: 필요 없음. 바깥 서비스에는 시드마다 1초 쉬며 요청한다.
- 오늘 돌린 결과: 결과_2026-11-11.tsv
다음 하네스: 2_겹침_대조 (이 결과를 그대로 입력으로 쓴다)
