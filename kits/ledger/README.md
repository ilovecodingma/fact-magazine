# 가계부 표 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 가계부 쪽을 켜 줘. 날짜·분류·내용·금액을 입력하면 합계가 나오고 브라우저에만 저장되며 CSV 로 내보낼 수 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: 입력 표(브라우저에만 저장) + 분류별 합계 + CSV 내보내기(자료 파일 없음)
- **2분 안에 보는 결과**: /ledger/ 에서 금액을 추가하면 합계가 바로 바뀌고 새로 열어도 남아 있습니다
- **예시 자료**: `kits/ledger/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add ledger` 후 `python build.py`
- **서버**: 불필요
