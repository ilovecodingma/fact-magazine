# 전자책 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
python ebook.py → 글(posts)과 연재(novels)를 표지·차례가 있는 PDF 한 권으로 → /ebook/ 에 내려받기. /ebook/ 에서 PDF 를 내려받아 열면 표지와 차례가 있습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 전자책은 글(posts)과 연재(novels)를 브라우저의 인쇄 기능(PDF 로 저장)으로 묶습니다. 따로 설치할 것이 없습니다.
- 만든 PDF 는 ebooks/ 폴더에 두고 build.py 를 돌려야 사이트(/ebook/)에 내려받기가 생깁니다. PDF 만 만들고 빌드를 안 하면 사이트에 안 보입니다.
- PDF 는 만든 시점의 내용입니다. 글이 바뀌면 python ebook.py 를 다시 돌려야 옛 내용의 책이 공개되지 않습니다.

## ③ 한 번 해 보기
python ebook.py 를 돌려 ebooks/ 에 PDF 가 생기는지 보고, python build.py 후 /ebook/ 에서 내려받아 열어 보면 표지와 차례가 있습니다. (자가 시험은 이미 만들어 둔 PDF 만 확인하고, 새로 만들지는 않습니다.)

## ④ 바꿔 보기
posts/ 폴더에 짧은 글(.md) 하나를 더하고 python ebook.py 와 python build.py 를 돌려, /ebook/ 의 PDF 크기가 달라지는지 보세요.
