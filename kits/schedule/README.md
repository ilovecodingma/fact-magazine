# 일정·달력 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 일정 쪽을 켜 줘. kits/schedule/data/events.json 에 날짜별 일정을 적으면 /schedule/ 에서 지난 일정이 자동으로 아래로 내려가는지 확인해 줘.

- **넣는 것 → 나오는 것**: 일정 목록(날짜·제목) → 다가오는 일정 + 지난 일정(오늘 기준 자동 분류)
- **2분 안에 보는 결과**: /schedule/ 에 지난 일정은 흐리게 아래에 모입니다(쪽을 다시 찍지 않아도)
- **예시 자료가 이미 들어 있습니다**: `kits/schedule/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add schedule`(지금 켜진 것에 더하기) 또는 `python mix.py schedule`(이것만) 후 `python build.py`
- **서버**: 불필요
