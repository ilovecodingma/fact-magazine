# 글 PDF 미리 만들기 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
글(마크다운) → 글마다 PDF(바뀐 글만 다시) + 글 쪽에 내려받기. 글 쪽 위에 「이 글을 PDF 로 내려받기」가 붙습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- python pdf.py 는 posts/*.md 마다 PDF 를 pdfs/ 에 만듭니다. 내용이 바뀐 글만 다시 만들어 빠릅니다.
- 글 쪽의 PDF 내려받기 링크는 pdfs/ 에 PDF 가 있을 때만 붙습니다. 그러므로 pdf.py 를 먼저, build.py 를 나중에 돌립니다.
- PDF 는 브라우저(Edge·Chrome)의 인쇄 기능으로 만듭니다. 설치할 것은 없지만 브라우저는 있어야 합니다.

## ③ 한 번 해 보기
python pdf.py 후 python build.py 를 돌리면 글 쪽 위에 「이 글을 PDF 로 내려받기」가 붙습니다. (자가 시험은 이미 만들어 둔 PDF 만 확인합니다.)
