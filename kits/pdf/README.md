# 글 PDF 미리 만들기 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 내 글을 PDF 로 미리 만들어 줘. python pdf.py 를 돌리고(바뀐 글만 다시 만들게), 빌드해서 글 쪽에 PDF 내려받기가 붙는지 확인해 줘.

- **넣는 것 → 나오는 것**: 글(마크다운) → 글마다 PDF(바뀐 글만 다시) + 글 쪽에 내려받기
- **2분 안에 보는 결과**: 글 쪽 위에 「이 글을 PDF 로 내려받기」가 붙습니다
- **예시 자료가 이미 들어 있습니다**: `kits/pdf/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add pdf`(지금 켜진 것에 더하기) 또는 `python mix.py pdf`(이것만) 후 `python build.py`
- **서버**: 불필요
