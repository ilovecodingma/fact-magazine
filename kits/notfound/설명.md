# 404 쪽·길 안내 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
(자료 없음) → docs/404.html: 없는 주소에서 검색·주요 쪽으로 안내. 없는 주소를 열면 「찾는 쪽이 없습니다」와 검색 링크가 나옵니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 404 쪽은 없는 주소로 들어온 방문자에게 길을 안내하는 쪽(docs/404.html)입니다. 호스팅(GitHub Pages 같은 곳)이 없는 주소를 만나면 이 파일을 보여 줍니다.
- 안내에는 처음 화면과 켜진 쪽의 링크가 자동으로 들어갑니다. 꺼진 키트 링크는 들어가지 않아 막다른 길이 안 생깁니다.
- 검색 키트가 켜져 있으면 「사이트 안 검색으로 찾기」도 더해집니다.

## ③ 한 번 해 보기
python build.py 후 docs/404.html 을 열어 보거나, 사이트가 올라간 뒤 주소 끝에 없는 글자를 붙여 열어 봅니다(예: /없는쪽/).

## ④ 바꿔 보기
python build.py 를 돌린 뒤 docs/404.html 을 브라우저로 열어(파일을 더블클릭) 안내 문구와 링크를 확인해 보세요.
