# 404 쪽·길 안내 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 없는 주소로 왔을 때 보이는 404 쪽을 켜 줘. 검색과 둘러볼 곳 링크가 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: (자료 없음) → docs/404.html: 없는 주소에서 검색·주요 쪽으로 안내
- **2분 안에 보는 결과**: 없는 주소를 열면 「찾는 쪽이 없습니다」와 검색 링크가 나옵니다
- **예시 자료**: `kits/notfound/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add notfound` 후 `python build.py`
- **서버**: 불필요
