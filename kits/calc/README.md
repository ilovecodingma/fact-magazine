# 계산기 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소로 계산기 하나 만들어 줘. 「목표 금액을 기간 안에 모으려면 매달 얼마」를 계산하는 저축 목표 계산기를 kits/calc 의 자료 파일에 넣고 빌드해서 숫자를 넣으면 결과가 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 자료 파일(`kits/calc/data/calculators.json`)에 식을 적으면 → /calc/ 목록과 계산기 쪽(브라우저에서 바로 계산, 서버 없음)
- **예시가 이미 들어 있습니다**: 켜기만 하면 계산기 **두 개**(저축 목표·복리)가 나옵니다. **새로 만들려면** 자료 파일에 한 덩어리(`slug`·`title`·`desc`·`inputs`·`vars`·`results`)를 더하고 빌드하세요. 식에는 숫자·입력 이름·`Math.pow` 같은 수학 함수만 씁니다.
- **2분 안에 보는 결과**: /calc/saving-goal/ 에서 목표 금액·기간을 바꾸면 매달 저축액이 바로 바뀝니다
- **사이트 어디에 붙나**: 메뉴 「계산기」, /calc/
- **서버**: 불필요 · **따라 하는 시간**: 약 5분
- **켜기**: `python mix.py calc`(또는 `site.json` 의 `parts` 에서 `calc` 켜기) 후 `python build.py`
- **자료 위치**: `kits/calc/data/`
