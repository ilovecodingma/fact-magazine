# 내용 하네스 2. 제목 다듬기

이렇게 입력하세요: `python -X utf8 run.py 제목후보.txt 결과.md`

- 넣는 것: 제목후보.txt — 하네스 4 의 제목 후보를 한 줄에 하나씩
- 나오는 것: 결과.md — 검색어마다 제목 5개와 「고른 이유」
- 2분 안에 보는 결과: 5개 중 하나를 고르고, 이유 문장을 보며 마음에 드는 부분만 손본다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 한계: 미리 정해 둔 틀 5개에 검색어를 끼운 것이다. 글 내용을 읽지는 않는다. 조사가 어색하면 사람이 고친다.
