# 제목 다듬기

규칙: 과장(충격·대박)·느낌표 없음, 검색어를 앞쪽에, 질문에 답이 되는 제목. 아래는 틀로 만든 후보이니 마지막은 사람이 고른다.

## 기초연금 금액
1. 기초연금 금액 총정리: 숫자와 날짜 한눈에 — 이유: 검색어가 맨 앞에 있고, 글에서 얻을 것(숫자·날짜)을 약속한다.
2. 기초연금 금액 2026년 기준, 공식 자료로 확인 — 이유: 연도가 있어 최신 글로 읽히고, 「공식 자료」로 신뢰를 준다.
3. 기초연금 금액, 헷갈리기 쉬운 점만 정리 — 이유: 독자가 막히는 지점을 겨냥해 클릭할 이유를 만든다.
4. 기초연금 금액, 어디서 확인하나? 기관 안내 모음 — 이유: 질문형이라 검색창 문장과 가깝고, 답(기관 안내)이 있다고 알려 준다.
5. 기초연금 금액 신청 전에 볼 숫자 3가지 — 이유: 숫자(3가지)가 있어 분량이 짐작되고, 신청 직전의 독자를 겨냥한다.
