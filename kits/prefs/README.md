# 글자 크기·어두운 바탕 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 방문자가 글자 크기와 어두운 바탕을 고를 수 있게 켜 줘. 푸터의 보기 설정 버튼을 눌러 바뀌고, 쪽을 새로 열어도 기억되는지 확인해 줘.

- **넣는 것 → 나오는 것**: (자료 없음) → 푸터 「보기 설정」 단추(글자 작게·크게, 어두운 바탕) + 이 브라우저에만 기억
- **2분 안에 보는 결과**: 푸터의 단추를 누르면 글자와 바탕이 바뀌고 새로 열어도 유지됩니다
- **예시 자료**: `kits/prefs/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add prefs` 후 `python build.py`
- **서버**: 불필요
