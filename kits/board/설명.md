# 게시판 키트 설명 뼈대
(순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤생각을 묻는 물음)

## ① 무엇
글자 위주 목록·추천(▲)·점수÷시간 순위·새 글/묻는 글/보여 주기 탭·들여쓴 댓글과 접기·지침 쪽·글 올리기·신고, 운영자 화면에서 승인·숨김. 서버가 꺼져 있으면 예시 글로 화면만 보임.

## ② 레퍼런스(해커 뉴스)는 이렇게 한다
- 글자 위주의 단순한 목록이라 빨리 훑고 나간다.
- 추천 점수를 지난 시간으로 나눠 순서를 정해 첫 화면이 계속 바뀐다.
- 지침으로 올릴 글의 결을 좁혀 놓았다.

## ③ 한 번 해 보기
`/키트 board` — 글 올리기 → 운영자 승인 → 목록 → 추천 → 탭 → 지침.

## ④ 바꿔 보기
python run.py 손잡이 순위셈법 2.5 로 돌려 예시 글의 순서가 어떻게 바뀌는지 보세요(서버 없이도 예시 글로 보입니다).

3. 지침에 무엇을 적어야 내가 바라는 글이 올라올까요?
