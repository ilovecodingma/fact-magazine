# 관련 글 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 글과 노트 아래에 관련 글 3개를 붙여 줘(같은 태그나 낱말이 겹치는 것). 켜고 빌드해서 글 쪽 아래에 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 글·노트의 태그·낱말 → 쪽 아래 「관련 글」 3개
- **2분 안에 보는 결과**: 글 쪽 맨 아래에 「관련 글」이 나옵니다(태그가 붙은 글이 둘 이상일 때)
- **예시 자료**: `kits/related/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add related` 후 `python build.py`
- **서버**: 불필요
