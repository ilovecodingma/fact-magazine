# 알리기 하네스 4. 한 주 홍보 계획표

이렇게 입력하세요: `python -X utf8 run.py 글목록.tsv 결과.md 2026-11-16`

- 넣는 것: 글목록.tsv (한 줄에 「글 제목 탭 글 주소」, 위에서부터 차례로 배정), 마지막 값 = 월요일 날짜
- 나오는 것: 결과.md — 7일 표(날짜·요일·블로그·영상·소식 메일)와 한 주 합계
- 규칙: 평일에 하루 한 편씩 블로그, 영상은 블로그에 먼저 올린 글을 하루 뒤에, 소식 메일은 금요일에 주 1회(받겠다고 한 사람에게만). 하루 채널당 1건을 넘기지 않는다. 한도는 run.py 위쪽 LIMIT 에서 바꾼다.
- 2분 안에 보는 결과: 요일마다 올릴 글이 하나씩 있는지, 주말이 비어 있는지 본다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다. 표만 만들고 올리지 않는다.
