# 하네스 8. 글 주소가 열리는지·검색에서 막혀 있지 않은지 확인

이렇게 입력하세요: `python -X utf8 run.py 주소.txt 결과.md`

- 넣는 것: 주소.txt — 한 줄에 주소 하나(사이트맵의 주소를 붙여 넣으면 됨)
- 나오는 것: 결과.md — 주소별 상태 번호, noindex 여부(페이지 안 robots 표시·응답 머리글), robots.txt 허용 여부, 맨 아래에 통과 수
- 2분 안에 보는 결과: 「통과」가 아닌 줄만 본다. 404 면 주소 오타나 아직 안 올라간 것, noindex 면 검색에서 일부러 뺀 글이다.
- 로그인·계정: 필요 없음. 주소마다 1초 쉬며 열어 본다.
- 오늘 돌린 결과: 결과_2026-11-11.md (마지막 줄은 일부러 없는 주소를 넣어 404 가 어떻게 보이는지 보여 줌)

- **한계**: 정부 사이트처럼 쿠키·리다이렉트(307)를 쓰는 곳은 처음 한 번 튕겨서 「열리지 않음」으로 표시될 수 있습니다. 실제로는 쿠키를 받아 다시 열면 열리는 경우가 있으니, 표시가 이상하면 브라우저로 직접 열어 확인하세요.
