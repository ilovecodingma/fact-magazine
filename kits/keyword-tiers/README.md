# 하네스 5. 검색어를 단기·중기·장기 칸으로 나누기

이렇게 입력하세요: `python -X utf8 run.py 입력.tsv 결과.md 2026-11-11`

- 넣는 것: 입력.tsv — 한 줄에 「검색어 탭 처음 본 날 탭 급상승/꾸준(비워도 됨)」, 마지막 값 = 오늘 날짜
- 나오는 것: 결과.md — 칸(단기/중기/장기)별 표. 단기는 4일 뒤, 중기는 14일 뒤에 지울지 다시 본다. 장기는 지우지 않는다.
- 2분 안에 보는 결과: 「지금 지우거나 결정」 표시가 붙은 줄부터 처리한다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 오늘 돌린 결과: 결과_2026-11-11.md
