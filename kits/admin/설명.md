# 운영자 화면 키트 설명 뼈대
(순서: ①무엇 ②왜(꼭 알아야 할 것) ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
/admin/ — 오늘 방문·인기 쪽·새 댓글·문의·소식 받기 수·하루 한 바퀴 기록·올릴 묶음을 한 화면에(휴대폰 폭도 됨). 로컬 암호(해시만 저장).

## ② 왜 이렇게 만들었나
- 운영자 암호는 서버 쪽에 해시로만 저장하고, 로그인하면 8시간짜리 쿠키를 준다
- 틀린 암호를 여러 번 넣으면 잠깐 막는다
- 바깥에 열 때는 이 화면 주소와 암호가 가장 중요한 방어선이다

## ③ 한 번 해 보기
`/키트 admin` — 서버를 임시로 켜서 화면에서 눌러 보고 결과를 확인합니다(도커가 없으면 「도커가 있으면 됩니다」로 건너뜁니다).

## ④ 바꿔 보기
python run.py 서버 암호 로 암호를 바꾸고 다시 로그인해 보세요.
