# 알리기 하네스 1. 글 한 편 → 블로그용 글

이렇게 입력하세요: `python -X utf8 run.py 글.md https://내사이트/글주소/ 결과.md`

- 넣는 것: 글.md (우리 사이트의 글 한 편), 그 글의 주소
- 나오는 것: 결과.md — 제목, 이 글에서 다룬 것(소제목 목록), 핵심 숫자(숫자 둘레 짧은 구절), 출처, 끝에 원문 주소와 사이트 소개 한 줄
- 2분 안에 보는 결과: 실행 마지막 줄의 「원문과 겹침 %」를 본다. 낮을수록 원문을 그대로 베끼지 않은 것이다. 핵심 숫자 구절이 글과 같은지 눈으로 대조한다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다. 블로그에 올리는 일은 하지 않는다(파일까지만).
- 한계: 문장을 새로 지어 쓰는 도구가 아니다. 소제목과 숫자 구절로 뼈대를 만든다. 문단 몇 개를 더 쓰고 싶으면 에이전트에게 「이 결과.md 를 바탕으로 원문과 다른 문장으로 두 문단을 더 써 줘」라고 시킨다.
- 오늘 돌린 결과: 결과_2026-11-11.md
