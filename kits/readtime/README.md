# 읽는 시간·목차 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 글 쪽에 읽는 데 걸리는 시간과 소제목 목차를 자동으로 붙여 줘. 켜고 빌드해서 글 쪽 위에 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 글(마크다운) → 글 쪽 위 「읽는 데 약 N분」 + 소제목 목차(소제목이 둘 이상일 때)
- **2분 안에 보는 결과**: 글 쪽 위에 읽는 시간과 목차가 나오고 목차를 누르면 그 소제목으로 갑니다
- **예시 자료**: `kits/readtime/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add readtime` 후 `python build.py`
- **서버**: 불필요
