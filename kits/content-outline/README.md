# 내용 하네스 1. 글 뼈대 만들기

이렇게 입력하세요: `python -X utf8 run.py 묶음.txt 결과.md`

- 넣는 것: 묶음.txt — 같은 주제의 검색어를 한 줄에 하나씩(하네스 4 의 「같은 묶음」을 붙여 넣으면 됨)
- 나오는 것: 결과.md — 소제목 순서와 소제목마다 답할 질문, 담을 검색어, 근거로 쓸 공식 자료 칸
- 2분 안에 보는 결과: 소제목 순서를 읽고 빠진 질문이 없는지 본다. 공식 자료 칸은 사람이 직접 채운다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 한계: 검색어 속 낱말(금액·신청·조건 등)로만 소제목을 정하는 단순한 규칙이다.
- 오늘 돌린 결과: 결과_2026-11-11.md
