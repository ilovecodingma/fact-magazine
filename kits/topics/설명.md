# 주제 묶음·허브 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
관련 있는 글·용어·계산기를 주제별로 묶어 목록 쪽과 주제마다 허브(모아 둔 길잡이) 쪽을 만들어 주는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 주제는 topics.json 의 한 덩어리(key·name·intro·items)다 — key 는 주소로, name·intro 는 화면 글로 쓰이기 때문입니다.
- 항목의 url 은 이 사이트 안에 실제로 있는 쪽 주소를 적는다 — 허브는 링크만 걸 뿐 쪽을 만들어 주지는 않기 때문입니다.
- 주제 목록 쪽(/topics/)은 푸터 링크로만 이어지고 메뉴에는 없다 — 키트 쪽 링크는 푸터에 모으는 규칙이기 때문입니다.

## ③ 한 번 해 보기
/topics/ 에서 주제를 누르면 소개와 항목 목록이 나옵니다. 화면 시험은 `python selftest.py topics --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
kits/topics/data/topics.json 의 첫 주제 intro 문장을 바꿔 python build.py 를 돌린 뒤 그 주제 쪽 맨 위 소개가 바뀌는지 보세요.
