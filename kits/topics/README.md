# 주제 묶음·허브 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소에 주제 묶음 쪽을 만들어 줘. kits/topics/data/topics.json 에 주제 두 개와 항목을 적고 빌드해서 /topics/ 목록과 주제별 쪽이 열리는지 확인해 줘.

- **넣는 것 → 나오는 것**: 주제 목록(JSON: 이름·소개·항목) → 주제별 허브 쪽 + 목록
- **2분 안에 보는 결과**: /topics/ 에서 주제를 누르면 소개와 글 목록이 나옵니다
- **예시 자료가 이미 들어 있습니다**: `kits/topics/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add topics`(지금 켜진 것에 더하기) 또는 `python mix.py topics`(이것만) 후 `python build.py`
- **서버**: 불필요
