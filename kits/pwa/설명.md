# 앱처럼 설치(PWA) 키트 설명 뼈대
(순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
사이트를 폰·PC 의 홈 화면에 앱처럼 추가하고, 인터넷이 없어도 열리게 하는 키트입니다. 서버를 새로 두지 않습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- manifest(이름·아이콘·색)와 서비스 워커(오프라인 저장) 두 가지가 있으면 브라우저가 「설치」를 띄웁니다.
- 127.0.0.1(내 PC 안)에서는 시험만 되고, 다른 기기에 설치하려면 https 공개 주소가 필요합니다.
- 웹 앱은 스토어 심사가 없고, 스토어 앱은 개발자 계정과 심사가 필요합니다(이 키트는 글로만 안내).

## ③ 한 번 해 보기
`/키트 앱` — 설치 가능 확인 → 가계부에 12,000원 → 인터넷 끔 → 다시 열어도 남아 있음.

## ④ 바꿔 보기
가계부에 오늘 쓴 돈을 한 줄 적고 비행기 모드로 다시 열어 보세요. 사이트 색(site.local.json 의 accent)을 바꾸면 아이콘 색도 바뀝니다.

2. 「127.0.0.1 에서는 시험만」 — 친구 폰에 설치하려면 무엇이 필요할까요?
3. 「웹 앱과 스토어 앱」 — 심사가 필요한 쪽은 어느 쪽일까요?
