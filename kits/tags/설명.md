# 태그 쪽 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
글·노트의 태그 → /tags/ 태그 목록 + 태그별 목록 쪽. /tags/ 에서 태그를 누르면 그 태그가 붙은 글·노트가 나옵니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 글의 태그는 kits/tags/data/post_tags.json 에, 확인 노트의 태그는 노트 파일의 tags 에 적습니다. 글(마크다운)에는 태그 칸이 따로 없기 때문입니다.
- 태그마다 쪽이 만들어지고, 글이 3개 미만인 태그 쪽은 검색에 나가지 않게(noindex) 해 둡니다.
- 태그 이름은 글자가 똑같아야 한 묶음이 됩니다. 「세금」과 「세금 제도」는 다른 태그입니다.

## ③ 한 번 해 보기
/tags/ 에서 태그(예: #세금)를 누르면 그 태그가 붙은 글이 나옵니다.

## ④ 바꿔 보기
kits/tags/data/post_tags.json 에서 isa-tax-free-limit 글의 태그에 "예시" 를 하나 더하고 python build.py 후 /tags/ 에 #예시 가 생기는지 보세요.

3. 「태그 이름은 글자가 똑같아야 한 묶음이 됩니다」 — 모르면 어떤 일이 생길까요?
