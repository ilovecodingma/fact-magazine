# 설문·투표 모양 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
문항 자료 → 고르면 내 선택만 브라우저에 저장되는 설문(모두의 결과는 서버 필요). /survey/ 에서 고르고 쪽을 새로 열어도 내 선택이 남아 있습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 문항은 자료 파일(kits/survey/data/survey.json)에 질문과 보기로 적습니다. 화면 코드는 건드리지 않아도 됩니다.
- 고른 답은 방문자 브라우저(localStorage, 브라우저 안의 작은 저장 칸)에만 저장되고 어디로도 보내지지 않습니다. 그래서 쪽을 새로 열어도 내 선택은 남지만 남의 선택은 알 수 없습니다.
- 모두의 결과를 모으려면 방문자의 선택을 받아 모으는 서버가 따로 필요합니다. 이 키트는 서버 없이 되는 데까지만 합니다.

## ③ 한 번 해 보기
/survey/ 에서 몇 가지를 고르고 쪽을 새로 열어 보세요. 고른 것이 그대로 남아 있고 「내 선택 N개가 이 브라우저에 저장되었습니다」가 나옵니다.

## ④ 바꿔 보기
kits/survey/data/survey.json 의 첫 질문(q)과 보기(options)를 내 주제로 바꾸고 python build.py 로 /survey/ 를 다시 열어 보세요.
