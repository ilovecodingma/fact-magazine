# 설문·투표 모양 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 설문 쪽을 켜 줘. kits/survey/data/survey.json 의 문항을 고르면 내 선택만 이 브라우저에 저장되고, 모두의 결과를 모으려면 서버가 필요하다는 안내가 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: 문항 자료 → 고르면 내 선택만 브라우저에 저장되는 설문(모두의 결과는 서버 필요)
- **2분 안에 보는 결과**: /survey/ 에서 고르고 쪽을 새로 열어도 내 선택이 남아 있습니다
- **예시 자료**: `kits/survey/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add survey` 후 `python build.py`
- **서버**: 불필요
