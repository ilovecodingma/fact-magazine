# 체크리스트·퀴즈 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 퀴즈 쪽을 켜 줘. kits/quiz/data/quiz.json 에 문항·보기·정답·해설을 적으면 /quiz/ 에서 풀고 채점되는지 확인해 줘.

- **넣는 것 → 나오는 것**: 문항 자료(JSON) → 브라우저에서 푸는 퀴즈(결과는 그 브라우저에만)
- **2분 안에 보는 결과**: /quiz/ 에서 풀고 「채점하기」를 누르면 점수와 해설이 나옵니다
- **예시 자료가 이미 들어 있습니다**: `kits/quiz/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add quiz`(지금 켜진 것에 더하기) 또는 `python mix.py quiz`(이것만) 후 `python build.py`
- **서버**: 불필요
