# 내용 하네스 4. 사이트 문구 세트

이렇게 입력하세요: `python -X utf8 run.py "파이어족 뉴스" "돈·생활 뉴스 속 제도·숫자" 결과.md`

- 넣는 것: 사이트 이름, 주제(「…를 공식 자료로 확인」 앞에 들어갈 말)
- 나오는 것: 결과.md — 한 줄 소개, title, description, 메뉴 이름 (글자 수도 표시)
- 2분 안에 보는 결과: 첫 문장에서 사이트가 하는 일이 보이는지 읽고 손본다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 오늘 돌린 결과: 결과_2026-11-11.md
