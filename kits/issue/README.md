# 잡지(호 발행) 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 오늘 확인 노트로 잡지 호를 발행해 줘. build.py → issue.py → build.py 순서로 돌리고 PDF 가 몇 쪽인지 알려 줘.

- **넣는 것 → 나오는 것**: 그날 노트 → 호 쪽 + 인쇄용 PDF
- **2분 안에 보는 결과**: /issue/ 에서 제1호와 PDF 링크가 뜹니다
- **파일 위치·붙는 곳**: issue.py · 메뉴 「잡지」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py issue` 후 `python build.py`
