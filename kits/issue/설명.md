# 잡지(호 발행) 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
그날의 확인 노트를 한 권으로 묶어 「제N호」 쪽과 인쇄용 PDF 로 내는 잡지입니다. 호가 있어야 잡지 쪽이 채워집니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 잡지 호는 `build → issue → build` 순서로 만든다 — 첫 build 가 호 쪽을 만들고, issue.py 가 PDF 를 찍고, 두 번째 build 가 PDF 링크를 붙이기 때문입니다.
- 확인 노트가 0건이면 호가 없다(목록에 「첫 호 준비 중」만 보임) — 호는 그날의 노트를 묶어 만들기 때문입니다.
- 노트가 늘면 PDF 도 다시 만들어야 하고, 이 스크립트는 내용이 바뀌면 다시 만든다 — 처음에는 PDF 가 있으면 건너뛰어 3건짜리 PDF 가 5건짜리 호에 붙었기 때문입니다.

## ③ 한 번 해 보기
/issue/ 목록에서 제1호를 누르면 그날의 노트가 판정 딱지와 함께 줄지어 나오고, 위에 PDF 내려받기 링크가 있습니다. 화면 시험은 `python selftest.py issue --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
notes/ 의 노트 한 건의 date 를 다른 날짜로 바꾸고 build → issue → build 순서로 돌려, /issue/ 목록에 호가 하나 더 생기는지 보세요.
