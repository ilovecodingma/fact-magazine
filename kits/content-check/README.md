# 내용 하네스 3. 글 점검

이렇게 입력하세요: `python -X utf8 run.py 글.md 결과.md`

- 넣는 것: 글.md — 점검할 글 한 편(마크다운)
- 나오는 것: 결과.md — ① 숫자가 있는데 같은 문단에 출처 낱말(주소·법령·기관 이름)이 없는 문단 ② 과장 낱말(충격·무조건·반드시…) ③ 80자를 넘는 긴 문장
- 2분 안에 보는 결과: 표에 나온 위치로 가서 출처를 붙이거나, 문장을 나누거나, 낱말을 바꾼다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 한계: 낱말과 길이만 보는 단순 점검이다. 숫자가 맞는지는 공식 자료를 직접 열어 확인해야 한다.
- 오늘 돌린 결과: 결과_2026-11-11.md (예시 글: 연금저축·IRP 세액공제 한도)
