# 자주 묻는 질문 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
질문과 답을 적어 두면 질문을 누를 때 답이 펴지는 쪽을 만들고, 검색 엔진이 읽는 구조 데이터도 같이 넣어 주는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 질문·답은 faq.json 에 {q, a} 로 한 건씩 적는다 — 빌드가 목록을 순서대로 접었다 펴는 칸으로 바꾸기 때문입니다.
- 접었다 펴는 일은 서버 없이 브라우저의 details 기능이 한다 — details 는 글자만으로 펴고 접는 기본 부품이기 때문입니다.
- 같은 질문·답이 검색용 구조 데이터(JSON-LD)로도 찍히므로, 쪽에 보이는 답과 같아야 한다 — 검색 엔진은 보이는 글과 구조 데이터가 같은지 보기 때문입니다.

## ③ 한 번 해 보기
/faq/ 에서 질문을 눌러 답을 펴 보고, 다시 눌러 접어 봅니다. 화면 시험은 `python selftest.py faq --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
kits/faq/data/faq.json 에 {"q": "내 질문?", "a": "내 답."} 한 줄을 더하고 python build.py 후 질문이 늘었는지 보세요.
