# 자주 묻는 질문 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 자주 묻는 질문 쪽을 켜 줘. kits/faq/data/faq.json 에 질문과 답을 적으면 /faq/ 에서 접었다 펴지는지 확인해 줘.

- **넣는 것 → 나오는 것**: 질문·답 목록(JSON) → /faq/ 접었다 펴는 쪽(검색용 구조 데이터 포함)
- **2분 안에 보는 결과**: /faq/ 에서 질문을 누르면 답이 펴집니다
- **예시 자료가 이미 들어 있습니다**: `kits/faq/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add faq`(지금 켜진 것에 더하기) 또는 `python mix.py faq`(이것만) 후 `python build.py`
- **서버**: 불필요
