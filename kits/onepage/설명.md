# 한 장 요약 인쇄 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
글·노트 → A4 한 장 점검표 PDF(핵심 세 줄 + 체크칸). /onepage/ 에서 PDF 를 내려받아 열면 한 장짜리 점검표가 있습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- python onepage.py 는 글과 확인 노트마다 A4 한 장 점검표 PDF 를 onepage/ 에 만듭니다(예시 노트는 빠집니다).
- PDF 를 만든 뒤 python build.py 를 돌려야 /onepage/ 에 내려받기가 생깁니다.
- 한 장에는 핵심 세 줄과 체크칸만 담습니다. 인쇄해서 체크하는 용도라 한 장을 넘기지 않습니다.

## ③ 한 번 해 보기
python onepage.py → python build.py 후 /onepage/ 에서 PDF 를 열면 한 장짜리 점검표가 있습니다. (자가 시험은 이미 만들어 둔 PDF 만 확인합니다.)

## ④ 바꿔 보기
posts/ 의 글 하나에 소제목(### 로 시작하는 줄)을 더하고 python onepage.py → python build.py 를 돌려, 그 글의 한 장 요약 PDF 가 바뀌는지 열어 보세요(끝나면 되돌리세요).
