# 한 장 요약 인쇄 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> python onepage.py 로 글과 노트를 A4 한 장 점검표 PDF 로 만들고, 빌드해서 /onepage/ 에서 내려받을 수 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: 글·노트 → A4 한 장 점검표 PDF(핵심 세 줄 + 체크칸)
- **2분 안에 보는 결과**: /onepage/ 에서 PDF 를 내려받아 열면 한 장짜리 점검표가 있습니다
- **예시 자료**: `kits/onepage/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add onepage` 후 `python build.py`
- **서버**: 불필요
