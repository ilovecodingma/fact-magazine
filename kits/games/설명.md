# 웹 게임 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
폴더 하나(meta.json+game.js) → 게임 쪽 + 목록. /games/ 에서 게임을 눌러 한 판 합니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 게임은 폴더 하나(meta.json 은 이름·설명 같은 정보 파일, game.js 는 게임 동작)로 games/ 에 둡니다. 빌드(build.py, 사이트 쪽을 만드는 명령)가 docs/ 로 복사하므로 docs/ 안을 직접 고치면 다음 빌드에 사라집니다.
- 게임을 고치면 meta.json 의 ver 를 올립니다. 그래야 방문자의 브라우저가 옛 판을 계속 쓰지 않습니다.
- 최고 기록은 방문자 브라우저(localStorage, 브라우저 안의 작은 저장 칸)에만 남습니다. 모두의 순위를 만들려면 서버가 따로 필요합니다.

## ③ 한 번 해 보기
`python -X utf8 selftest.py games --headless` 를 돌리면 목록 → 게임 쪽 → 캔버스 확인까지 자동으로 해 줍니다. 게임을 직접 해 보려면 /games/rumor/ 에서 화면을 끌어 움직여 보세요(자가 시험은 게임 플레이 자체는 시험하지 않습니다).

## ④ 바꿔 보기
games/rumor/meta.json 의 title(게임 이름)을 바꾸고 ver 숫자를 하나 올린 뒤 python build.py 로 /games/ 목록의 이름이 바뀌는지 보세요.
