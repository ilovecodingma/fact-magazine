# 웹 게임 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소의 games 폴더에 한 손으로 하는 작은 웹 게임을 하나 만들어 줘(meta.json + game.js, 캔버스). 빌드해서 /games/ 에 뜨고 휴대폰 폭에서 한 판 되는지 확인해 줘.

- **넣는 것 → 나오는 것**: 폴더 하나(meta.json+game.js) → 게임 쪽 + 목록
- **2분 안에 보는 결과**: /games/ 에서 게임을 눌러 한 판 합니다
- **파일 위치·붙는 곳**: games/ · 메뉴 「게임」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py games` 후 `python build.py`
