# 알리기 하네스 2. 글 한 편 → 짧은 알림 문구 세 길이 + 해시태그

이렇게 입력하세요: `python -X utf8 run.py 글.md https://내사이트/글주소/ 결과.md`

- 넣는 것: 글.md, 그 글의 주소
- 나오는 것: 결과.md — 한 줄 / 세 줄 / 다섯 줄 알림 문구, 해시태그 후보
- 2분 안에 보는 결과: 세 길이 중 올릴 곳에 맞는 것을 고르고, 숫자가 글과 같은지 본다. 과장 낱말이 없는지도 본다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다. 올리지 않는다(파일까지만).
- 한계: 숫자 구절은 글에서 그대로 잘라 온 것이라 앞뒤가 어색하면 사람이 다듬는다. 해시태그는 글 속 낱말 빈도로 뽑은 후보다.
