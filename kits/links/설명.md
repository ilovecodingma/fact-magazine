# 링크 모음 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
분류별로 링크를 적어 두면 링크 모음 쪽을 만들고, linkcheck.py 로 깨진 링크가 있는지 점검할 수 있는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 링크는 links.json 에 category 와 그 안의 items(name·url·desc)로 적는다 — 빌드가 분류마다 제목과 목록을 만들기 때문입니다.
- 링크는 시간이 지나면 깨지므로 python linkcheck.py 로 가끔 점검한다 — 주소가 바뀌거나 사라지는 일이 흔하기 때문입니다.
- linkcheck.py 는 바깥 사이트에 접속하므로 인터넷이 있어야 하고, 이 자가 시험은 접속하지 않는다 — 점검은 실제 주소에 요청을 보내야 알 수 있기 때문입니다.

## ③ 한 번 해 보기
/links/ 에 분류 제목과 링크가 나오고, 링크를 누르면 새 탭에서 바깥 사이트가 열립니다. 화면 시험은 `python selftest.py links --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).
