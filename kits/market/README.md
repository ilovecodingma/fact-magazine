# 디지털 상품 장터 키트 — 레퍼런스: 검로드

둘러보기(찾기 칸·분류 알약·추천 상품·정렬·거르기 상자·3열 상품 카드·분홍 값 딱지)와 상품 쪽(대표 그림·이름·판매자·평가·설명·값 딱지·살래요!·찜·공유·평가 막대·후기). 결제는 없고 주문 문의 또는 바깥 판매 주소로 보냄.

- 켜기: `python run.py 켜기 market` (주문 문의를 받으려면 `python run.py 서버`)
- 손잡이: 사는단추 · 값정하기 · 상품열 · 딱지색
- 혼자 못 하는 것: 결제·정산·세금 처리, 수많은 판매자와 구매자가 모여야 도는 둘러보기 추천
- 예시 상품·값·평가·후기는 모두 가상입니다.
