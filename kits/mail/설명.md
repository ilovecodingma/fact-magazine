# 소식지 메일 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
확인 노트 → 메일 한 통(SMTP, 기본은 미리보기). python mail.py 가 제목과 본문을 보여 줍니다(보내지 않음).

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- python mail.py 는 기본이 미리보기입니다. 제목과 본문만 화면에 보여 주고 메일은 보내지 않습니다. 실제로 보내려면 --send 를 붙여야 합니다.
- 메일을 보내는 길(SMTP)의 서버·포트·앱 비밀번호는 사람이 메일 서비스에서 받아 내 컴퓨터의 mail.local.json 에만 넣습니다(git 에 안 올라갑니다).
- 처음에는 내 주소로 한 통만 시험하고, 받는 사람은 수신을 허락한 분만 넣습니다.

## ③ 한 번 해 보기
python mail.py 를 돌려 화면에 제목과 본문이 나오는지 봅니다. 「미리보기입니다. 보내지 않았습니다」 줄이 맨 끝에 나오면 정상입니다. 자가 시험도 이 미리보기만 돌립니다.
