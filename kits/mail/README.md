# 소식지 메일 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> mail.py 로 오늘 확인 노트 소식지를 미리보기해 줘. 보내지는 말고, 내가 받는 주소를 확인하고 「보내」라고 하면 그때 --send 로 보내.

- **넣는 것 → 나오는 것**: 확인 노트 → 메일 한 통(SMTP, 기본은 미리보기)
- **2분 안에 보는 결과**: python mail.py 가 제목과 본문을 보여 줍니다(보내지 않음)
- **파일 위치·붙는 곳**: mail.py · mail.local.json(내 컴퓨터만) (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py mail` 후 `python build.py`
