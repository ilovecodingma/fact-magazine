# 디데이 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 디데이 쪽을 켜 줘. kits/dday/data/dates.json 의 날짜까지 며칠 남았는지가 브라우저에서 날마다 계산돼 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 날짜 목록 → 「D-며칠」 카드(쪽을 열 때마다 브라우저가 계산)
- **2분 안에 보는 결과**: /dday/ 에서 날짜마다 「D-12 (12일 남음)」처럼 나옵니다
- **예시 자료**: `kits/dday/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add dday` 후 `python build.py`
- **서버**: 불필요
