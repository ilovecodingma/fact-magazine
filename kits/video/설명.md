# 영상 모음 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
유튜브 영상 주소 목록을 적으면 /video/ 쪽에 영상 칸을 줄지어 넣어 주는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 영상 목록은 site.local.json 의 extras.videos 에 {url, title} 로 적는다 — 영상은 글 파일이 아니라 사이트 설정에서 읽기 때문입니다.
- 주소는 youtu.be/ID, youtube.com/watch?v=ID, youtube.com/shorts/ID 모양이어야 한다 — 빌드가 이 모양에서 11글자 영상 번호를 뽑아 칸을 만들기 때문입니다.
- 영상 칸은 보는 사람이 재생할 때 유튜브에 접속한다(빌드는 접속하지 않는다) — 칸은 유튜브 주소를 가리키는 틀일 뿐이기 때문입니다.

## ③ 한 번 해 보기
/video/ 에 영상 제목과 재생 칸, 「유튜브에서 보기」 링크가 나옵니다(시험은 바깥 접속 없이 칸이 생기는지만 봅니다). 화면 시험은 `python selftest.py video --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
site.local.json 의 extras.videos 에 내 영상 주소({"url": "https://youtu.be/…", "title": "제목"})를 한 줄 더하고 python build.py 를 돌려 영상 칸이 늘어나는지 보세요.
