# 영상 모음 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> site.local.json 의 extras.videos 에 내 유튜브 영상 주소를 넣고 빌드해서 /video/ 에 영상이 뜨는지 확인해 줘.

- **넣는 것 → 나오는 것**: 유튜브 주소 목록 → /video/ 임베드
- **2분 안에 보는 결과**: /video/ 에 영상이 뜹니다
- **파일 위치·붙는 곳**: extras.videos · 메뉴 「영상」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py video` 후 `python build.py`
