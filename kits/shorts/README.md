# 쇼츠 영상 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소의 확인 노트로 세로 쇼츠 영상을 만들어 줘(python shorts.py). 만든 뒤 길이·해상도·글자 잘림을 확인해서 알려 줘.

- **넣는 것 → 나오는 것**: 확인 노트 → 세로 영상 mp4 + 제목·설명 글
- **2분 안에 보는 결과**: shorts/ 폴더의 mp4 를 재생합니다(ffmpeg·Edge/Chrome 필요)
- **파일 위치·붙는 곳**: shorts.py · shorts/ (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py shorts` 후 `python build.py`
