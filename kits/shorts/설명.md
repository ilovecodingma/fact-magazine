# 쇼츠 영상 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
확인 노트 → 세로 영상 mp4 + 제목·설명 글. shorts/ 폴더의 mp4 를 재생합니다(ffmpeg·Edge/Chrome 필요).

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 쇼츠는 확인 노트의 문장만으로 세로 영상(mp4)을 만듭니다. 글 장면은 브라우저(Edge·Chrome)로 찍고 ffmpeg(영상을 묶는 무료 프로그램)로 이어 붙이므로 둘 다 있어야 합니다.
- 만든 영상은 자동 문턱(깨짐 없음·1080×1920·15~60초·소리 크기)을 못 넘으면 이름이 _보류로 바뀌어 올라가지 않습니다.
- 영상에 쓰는 말은 노트에 있는 것뿐입니다. 새 숫자·사실을 지어내지 않습니다. 유튜브에 올리는 일은 사람 승인 뒤 담당이 합니다.

## ③ 한 번 해 보기
ffmpeg 가 있으면 python shorts.py notes/예시-수출.json 한 줄로 shorts/예시-수출.mp4 와 제목·설명 글(.txt)이 생깁니다. ffmpeg 가 없으면 자가 시험은 「건너뜀」으로 알려 줍니다.

## ④ 바꿔 보기
notes/예시-수출.json 의 question(질문) 한 줄을 바꿔 python shorts.py notes/예시-수출.json 을 다시 돌려, 영상 첫 장면의 글이 바뀌는지 shorts/ 의 mp4 를 열어 보세요.
