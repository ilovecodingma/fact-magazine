# 표 비교 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 비교표 쪽을 켜 줘. kits/compare/data/table.json 에 열과 행을 적으면 /compare/ 에서 제목을 눌러 정렬하고 글자로 거를 수 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: 표 자료(열·행) → 정렬·거르기 되는 표
- **2분 안에 보는 결과**: /compare/ 에서 열 제목을 누르면 정렬되고 위 칸에 글자를 치면 줄이 걸러집니다
- **예시 자료가 이미 들어 있습니다**: `kits/compare/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add compare`(지금 켜진 것에 더하기) 또는 `python mix.py compare`(이것만) 후 `python build.py`
- **서버**: 불필요
