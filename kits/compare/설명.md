# 표 비교 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
열과 행을 적은 표 하나로, 제목을 누르면 정렬되고 위 칸에 글자를 치면 줄이 걸러지는 비교표 쪽을 만드는 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 표는 table.json 의 columns(열 이름)와 rows(줄)로 되어 있고, 줄마다 칸 수가 열 수와 같아야 한다 — 빌드가 열 순서대로 칸을 맞춰 넣기 때문입니다.
- 정렬은 브라우저가 한다: 숫자 칸은 크기순, 글자 칸은 가나다순 — 쪽 안의 자바스크립트가 보여 주는 값으로 줄을 다시 줄 세우기 때문입니다.
- 비교표의 값은 예시이고 조건은 서비스마다 다르다 — 이 키트의 예시 값은 시험용으로 만든 것이기 때문입니다.

## ③ 한 번 해 보기
/compare/ 에서 열 제목(난이도 등)을 눌러 정렬해 보고, 거르기 칸에 글자를 쳐서 줄이 줄어드는 것을 봅니다. 화면 시험은 `python selftest.py compare --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
kits/compare/data/table.json 의 rows 에 한 줄을 더(칸 수는 columns 와 같게) 적고 python build.py 를 돌려 표에 줄이 늘었는지 보세요.
