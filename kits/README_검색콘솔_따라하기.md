# 검색 콘솔 따라하기 — 사람이 로그인한 뒤 에이전트가 화면에서 읽어 오는 순서

하네스 9~11 은 로그인이 필요해 스크립트로 만들지 않고 순서만 적는다. 이 문서는 글이다. 실제 로그인·화면 조작은 이 문서를 쓰는 쪽에서 하지 않았다.
화면 이름은 서치 콘솔이 바뀌면 달라질 수 있어서, 아래 이름과 다르면 비슷한 이름의 메뉴를 찾는다.

공통 약속
- [사람] 로그인, 본인 인증, 소유권 확인, 약관 동의, 제출 버튼.
- [에이전트] 화면 읽기, 날짜·필터 칸 채우기, 읽은 숫자 적기.
- 에이전트가 읽은 숫자는 「화면에서 읽음」으로, 사람이 직접 본 것은 「직접 봄」으로 구분해 적는다.
- 서치 콘솔 화면 작업은 사람이 로그인해 둔 브라우저에서만 한다. 계정·메일·주소가 보이는 화면은 캡처할 때 가린다.

## 하네스 10. 어떤 검색어로 들어왔나 (검색 결과 실적)
넣는 것: 사이트 속성, 기간. 나오는 것: 검색어별 클릭·노출·평균 순위 표.
1. [사람] 서치 콘솔에 로그인하고 사이트 속성을 연다.
2. [에이전트] 왼쪽 메뉴에서 「실적」(검색 결과)을 연다.
3. [에이전트] 기간을 「최근 28일」로 고르고, 표 위 탭에서 「검색어」를 연다.
4. [에이전트] 클릭·노출 칸을 켜고, 클릭 많은 순으로 위 10줄을 적는다.
5. [에이전트] 「페이지」 탭으로 바꿔 어느 글이 클릭을 받았는지 위 10줄을 적는다.
2분 안에 보는 결과: 우리 글 주소 앞에 붙은 검색어가 글 제목의 말과 같은지 비교한다. 노출은 되는데 클릭이 없는 검색어는 제목을 손볼 후보다.
처음 며칠은 표가 비어 있을 수 있다. 그것은 오류가 아니라 아직 데이터가 없다는 뜻이다.

## 하네스 9. 글마다 첫 검색 방문까지 걸린 날 재기
넣는 것: 글 주소, 게시일. 나오는 것: 첫 클릭 또는 첫 노출이 생긴 날까지의 일수.
1. [사람] 로그인한 상태에서 사이트 속성을 연다.
2. [에이전트] 「실적」에서 필터에 「페이지」가 글 주소와 일치하도록 넣는다.
3. [에이전트] 기간을 게시일부터 오늘까지로 정하고, 표의 「날짜」 탭에서 일별 노출·클릭을 읽는다.
4. [에이전트] 처음으로 노출(또는 클릭)이 1 이상인 날을 적고, 그 날짜에서 게시일을 빼 걸린 날을 계산한다.
5. 같은 순서를 글마다 반복해 표 한 장(글 주소 / 게시일 / 첫 노출일 / 걸린 날)으로 모은다.
2분 안에 보는 결과: 글마다 걸린 날을 나란히 보고, 오래 걸리는 글에 공통점(주제, 길이)이 있는지 본다. 줍줍에서는 첫 검색 방문이 게시 후 중앙값 7일 정도로 측정됐으니 사흘 안에 결론 내리지 않는다.

## 하네스 11. 제목 바꿔 보기 실험 (실험군·비교군)
넣는 것: 글 20개. 나오는 것: 제목을 바꾼 쪽과 안 바꾼 쪽의 클릭 비교.
1. [사람·에이전트] 글 20개를 번호순으로 짝수·홀수로 나눈다. 한쪽(실험군)만 제목을 바꾸고, 다른 쪽(비교군)은 그대로 둔다. 바꾸는 날짜를 적는다.
2. [에이전트] 바꾸기 전 2주와 바꾼 뒤 2주를 같은 길이로 정해 「실적」의 날짜 비교 기능으로 두 기간의 클릭·노출을 읽는다(페이지 필터는 글마다 또는 주소 일부로).
3. [에이전트] 두 묶음의 클릭 합계와 변화량을 표 한 장으로 적는다.
2분 안에 보는 결과: 실험군이 비교군보다 늘었는지 본다. 한 번의 숫자로 결론 내지 않고 2주를 한 번 더 지켜본다.
주의: 노출 자체가 바뀔 수 있어서(검색어 순위 변동) 클릭 수만이 아니라 클릭률(클릭÷노출)도 함께 본다.

## 사람이 정해야 하는 것
- 어떤 글을 실험군에 넣을지, 실제로 제목을 바꿀지
- 로그인된 브라우저를 에이전트가 쓰도록 맡길지
