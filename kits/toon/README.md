# 웹툰 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> toons 폴더에 4컷 만화 1화를 넣고(그림은 SVG 로 글자와 도형만) 세로로 이어 보이는지 확인해 줘.

- **넣는 것 → 나오는 것**: 회차 그림 → 세로 이어 보기 화면
- **2분 안에 보는 결과**: /toon/ 에서 4컷이 세로로 이어집니다
- **파일 위치·붙는 곳**: toons/ · 메뉴 「웹툰」 (이 키트는 저장소 맨 위의 파일을 가리킵니다 — 파일을 옮기지 않았습니다)
- **켜기**: `python mix.py toon` 후 `python build.py`
