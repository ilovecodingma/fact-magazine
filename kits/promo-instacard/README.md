# 알리기 하네스 5. 글 한 편 → 인스타 카드 글자 + 본문 문구 + 해시태그

이렇게 입력하세요: `python -X utf8 run.py 글.md https://내사이트/글주소/ 결과.md`

- 넣는 것: 글.md, 그 글의 주소
- 나오는 것: 결과.md — 카드 한 장에 올릴 글자(큰 제목 한 줄 · 숫자 하나 · 출처 한 줄, 글자 수와 한도 표시), 본문 문구, 해시태그 후보
- 2분 안에 보는 결과: 「줄이기」 표시가 붙은 줄을 먼저 줄인다. 카드 속 숫자가 글과 같은지 확인한다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다. 그림은 만들지 않고(카드 그림 키트가 만든다) 올리지 않는다. 올리는 것은 사람이 「올려」 한 뒤에만.
- 한계: 글자 수 한도(제목 20자·숫자 12자·출처 28자·본문 300자·해시태그 8개)는 카드가 읽기 쉽게 정한 실습용 값이지 인스타그램이 정한 값이 아니다. 숫자는 글에서 가장 먼저 나오는 숫자 하나다.
