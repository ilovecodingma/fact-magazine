# 카드 그림 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> python card.py 로 확인 노트마다 공유용 카드 그림 한 장(PNG)을 만들고, 빌드해서 /cards/ 에서 내려받을 수 있는지 확인해 줘.

- **넣는 것 → 나오는 것**: 확인 노트 → 공유용 그림 한 장(도형과 글자, SVG·PNG) + /cards/ 내려받기
- **2분 안에 보는 결과**: /cards/ 에서 노트마다 카드 그림을 내려받습니다
- **예시 자료**: `kits/cards/data/`(있는 키트만, 일반 내용)
- **켜기**: `python mix.py --add cards` 후 `python build.py`
- **서버**: 불필요
