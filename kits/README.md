# 키트 규격

키트 = 5~10분 안에 하나만 해 보는 작은 하네스. 폴더 하나가 키트 하나입니다.

```
kits/<이름>/
  README.md   「이렇게 입력하세요」 한 줄 + 넣는 것·나오는 것 + 2분 안에 보는 결과 + 켜는 법
  kit.json    이름·한 줄 입력·나오는 것·붙는 곳·서버 필요 여부 + parts(켜질 부품 이름)
  data/       예시 자료(있으면)
```

- **켜기**: `python mix.py 키트1 키트2 …` → 고른 키트만 켜진 사이트가 찍힙니다(`site.json` 의 `parts` 를 바꿈). 지금 켜진 것에 더하려면 `--add`, 빼려면 `--off`.
- **예시 조합**: `python mix.py 예시조합이름` (`kits/mixes.json`). 목록은 `python mix.py`.
- 새 키트를 만들 때: `kit.json` 의 `parts` 에 켤 부품이 있으면 `build.py` 가 그 부품을 찍고, 없으면(내 컴퓨터에서 도는 도구) 폴더 안 스크립트를 직접 실행합니다.
- 키트 목록은 사이트의 `/kits/` 쪽에서도 보입니다(`parts.kits`).
- **원칙**: 서버·계정이 필요한 것은 키트로 만들지 않고 글로만 설명합니다. 우리 쪽 값은 키트 안에 넣지 않습니다.
