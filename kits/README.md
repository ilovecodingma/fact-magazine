# 키트 규격

키트 = 5~10분 안에 하나만 해 보는 작은 하네스. 폴더 하나가 키트 하나입니다.

```
kits/<이름>/
  README.md   「이렇게 입력하세요」 한 줄 + 넣는 것·나오는 것 + 2분 안에 보는 결과 + 켜는 법
  kit.json    이름·한 줄 입력·나오는 것·붙는 곳·서버 필요 여부 + parts(켜질 부품 이름)
  data/       예시 자료(있으면)
```

- **켜기**: `python mix.py 키트1 키트2 …` → **앞에 켜 둔 것을 모두 끄고** 고른 키트만 새로 켭니다(`site.json` 의 `parts` 를 바꿈). 지금 켜진 것에 **더하려면 `--add 키트`**, 빼려면 `--off 키트`.
- **사이트 이름·소개 바꾸기**: 내 컴퓨터 설정 파일 `site.local.json`(없으면 만들기)에 `{"name": "내 사이트 이름", "tagline": "한 줄 소개"}` 를 적습니다. 저장소에 올려도 되는 값이면 `site.json` 의 `name`·`tagline` 을 고쳐도 됩니다.
- **뉴스를 끄고 섞으면**: 첫 화면(메뉴 「처음」)에 켜진 키트의 것(게임·계산기·용어·글)이 모여 보입니다. 다만 들어 있는 **예시 게임 3개는 뉴스 소재**입니다 — 내 주제 게임으로 바꾸려면 Claude Code 에 「games 폴더의 게임 하나를 <내 주제> 소재로 바꿔 줘(meta.json 의 제목·설명과 game.js 의 글자)」라고 입력하세요.
- **예시 조합**: `python mix.py 예시조합이름` (`kits/mixes.json`). 목록은 `python mix.py`.
- 새 키트를 만들 때: `kit.json` 의 `parts` 에 켤 부품이 있으면 `build.py` 가 그 부품을 찍고, 없으면(내 컴퓨터에서 도는 도구) 폴더 안 스크립트를 직접 실행합니다.
- 키트 목록은 사이트의 `/kits/` 쪽에서도 보입니다(`parts.kits`).
- **원칙**: 서버·계정이 필요한 것은 키트로 만들지 않고 글로만 설명합니다. 우리 쪽 값은 키트 안에 넣지 않습니다.
