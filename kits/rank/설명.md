# 화제 순위 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
제목 목록(매체·제목) → 같은 화제끼리 묶은 순위. /rank/ 에 가장 많은 곳이 다룬 화제가 위에 나옵니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 재료는 「매체(탭)제목」 한 줄씩 적은 목록 파일(kits/rank/data/titles.tsv)입니다. 탭은 키보드의 Tab 글자입니다.
- 같은 화제인지는 제목 속 낱말이 겹치는 정도로 자동 판단합니다(낱말 2개 이상, 40% 이상). 단순한 규칙이라 완벽하지 않습니다.
- 순위는 서로 다른 매체가 몇 곳 다뤘는지 순서입니다. 많이 다뤘다는 것이 사실이라는 뜻은 아닙니다.

## ③ 한 번 해 보기
python build.py 후 /rank/ 를 열면 「1위 · 3곳이 다룸」처럼 많이 다룬 화제가 위에 나옵니다.

## ④ 바꿔 보기
kits/rank/data/titles.tsv 맨 아래에 「매체(탭)제목」 한 줄을 더하고 python build.py 후 /rank/ 의 순위가 바뀌는지 보세요(예시 제목만 쓰세요).
