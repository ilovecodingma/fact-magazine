# 화제 순위 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 화제 순위 쪽을 켜 줘. kits/rank/data/titles.tsv 의 제목 목록을 같은 화제끼리 묶어 몇 곳이 다뤘는지로 순위를 매기고 /rank/ 에 보여 줘.

- **넣는 것 → 나오는 것**: 제목 목록(매체·제목) → 같은 화제끼리 묶은 순위
- **2분 안에 보는 결과**: /rank/ 에 가장 많은 곳이 다룬 화제가 위에 나옵니다
- **예시 자료가 이미 들어 있습니다**: `kits/rank/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add rank`(지금 켜진 것에 더하기) 또는 `python mix.py rank`(이것만) 후 `python build.py`
- **서버**: 불필요
