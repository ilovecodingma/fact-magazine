# 하네스 2. 이미 쓴 글과 겹침 대조

이렇게 입력하세요: `python -X utf8 run.py 후보.tsv 이미쓴글.txt 결과.tsv`

- 넣는 것: 후보.tsv (하네스 1 의 결과 파일을 복사해 이름만 바꿈), 이미쓴글.txt (이미 쓴 글 제목, 한 줄에 하나)
- 나오는 것: 결과.tsv (검색어, 시드, 「새 주제」 또는 「겹침」)
- 2분 안에 보는 결과: 「새 주제」 줄만 훑어 본다. 겹침 줄은 이미 쓴 글을 고쳐 쓸 후보다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
- 한계: 시드가 제목에 나오는지만 본다(정밀하지 않음). 처음에는 이 정도로 충분하다.
- 오늘 돌린 결과: 결과_2026-11-11.tsv
