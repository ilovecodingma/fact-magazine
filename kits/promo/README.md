# 알리기 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> python promo.py 로 오늘 확인 노트의 블로그용 글과 짧은 알림 문구 세 가지 길이를 만들어 줘. 올리지는 말고 파일만 만들어서 보여 줘.

- **넣는 것 → 나오는 것**: 확인 노트 → 블로그용 글(요약+출처+사이트 링크) + 알림 문구 3가지 길이(파일)
- **2분 안에 보는 결과**: promo_out/ 에 노트별 폴더가 생기고 블로그글.md 와 알림_짧게·보통·길게.txt 가 있습니다(올리지는 않음)
- **켜기**: `python mix.py --add promo` 후 `python build.py`
- **서버**: 불필요
