# 사진첩 키트 설명 뼈대
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
폴더에 그림 파일을 넣으면 작은 그림 목록을 만들고, 누르면 화면 가득 크게 보여 주는 사진첩 기능입니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 그림은 kits/gallery/data/ 폴더에 넣은 png·jpg·svg·webp 파일이 전부 나온다 — 빌드가 폴더의 그림 파일을 이름순으로 읽기 때문입니다.
- 그림 설명은 captions.json 에 「파일이름: 설명」 으로 적는다 — 큰 그림 아래 글과 그림의 대체 글(alt)로 쓰이기 때문입니다.
- 크게 보기는 서버 없이 브라우저 안에서 그림을 덮어 보여 주는 방식이다(닫기: 화면 누르기·Esc) — 쪽 안의 작은 코드가 어두운 판 위에 그림을 띄우기 때문입니다.

## ③ 한 번 해 보기
/gallery/ 에서 그림을 눌러 크게 보고, 화면을 누르거나 Esc 키로 닫습니다. 화면 시험은 `python selftest.py gallery --headless` 로 돌려 볼 수 있습니다(브라우저가 알아서 눌러 보고 단계마다 ✓ 를 보여 줍니다).

## ④ 바꿔 보기
kits/gallery/data/captions.json 에서 그림 하나의 설명 글자를 바꾸고 python build.py 를 돌려 작은 그림 아래 글이 바뀌는지 보세요.
