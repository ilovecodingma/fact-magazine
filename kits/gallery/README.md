# 사진첩 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 사진첩을 켜 줘. kits/gallery/data 에 그림 파일을 넣으면 /gallery/ 에 작은 그림 목록이 나오고 누르면 크게 보이는지 확인해 줘.

- **넣는 것 → 나오는 것**: 그림 폴더 → 작은 그림 목록 + 크게 보기
- **2분 안에 보는 결과**: /gallery/ 에서 그림을 누르면 화면 가득 크게 보입니다
- **예시 자료가 이미 들어 있습니다**: `kits/gallery/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add gallery`(지금 켜진 것에 더하기) 또는 `python mix.py gallery`(이것만) 후 `python build.py`
- **서버**: 불필요
