# 상태 쪽 + 점검 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소에 상태 쪽을 켜고 audit.py 로 점검해 줘. 마지막 수집·피드 문제·노트 수·깨진 링크를 한 쪽에서 볼 수 있게 하고, 점검에서 나온 문제를 알려 줘.

- **넣는 것 → 나오는 것**: 켜기 + python audit.py → /status/ 쪽(마지막 수집·빌드, 피드별 건수와 실패, 노트·글·게임 수, 대조 결과, 점검 문제, 최근 커밋). 검색에는 안 나가게 noindex
- **2분 안에 보는 결과**: /status/ 한 쪽으로 오늘 사이트가 멀쩡한지 봅니다
- **사이트 어디에 붙나**: 푸터 「상태」, /status/
- **서버**: 불필요 · **따라 하는 시간**: 약 5분
- **켜기**: `python mix.py status`(또는 `site.json` 의 `parts` 에서 `status` 켜기) 후 `python build.py`
- **자료 위치**: `kits/status/data/`
