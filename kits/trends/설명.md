# 인기 키워드 키트 설명

## ① 무엇
구글 트렌드(한국)에서 요즘 많이 찾는 검색어 목록을 받아 와, 사이트 안에 「오늘의 인기 키워드」 쪽(/trends/)을 만드는 키트입니다. 키워드를 누르면 관련 보도 제목과 링크가 나옵니다. RSS(웹사이트가 새 글 목록을 기계가 읽기 좋게 내놓는 주소)를 한 번 받아서 정적인 쪽으로 굳히는 방식이라 서버가 필요 없습니다.

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 목록은 사이트를 만들 때(빌드) 한 번만 받습니다. 그래서 다시 빌드하기 전에는 내용이 바뀌지 않습니다. 못 받으면 마지막으로 성공한 목록(`data/trends_cache.json`)을 씁니다.
- 인기 검색어에는 사람 이름·사건 소식이 많아서, 그대로 보여 주면 사이트 기준(당사자 이야기는 다루지 않음)과 어긋납니다.
- 그래서 내 주제 낱말(`topic_words`)과 겹치는 것만 남기고 사건·사고 낱말(`block_words`)이 든 것은 뺍니다. 주제 낱말이 비어 있으면 아무것도 보여 주지 않는 것이 기본입니다.

## ③ 한 번 해 보기
`python selftest.py trends` 를 실행하면 사이트를 임시로 만들고 /trends/ 쪽이 열리는지 확인합니다(인터넷이 없으면 「건너뜀」으로 나옵니다). 직접 보려면 `python mix.py trends` 후 `python build.py` 를 하고 `dist/trends/index.html` 을 엽니다.

## ④ 바꿔 보기
`kits/trends/data/config.json` 의 `topic_words` 에 낱말을 하나 더 넣고 다시 빌드해 보세요. 목록이 늘거나 그대로인지 보면 거르기가 어떻게 일하는지 감이 옵니다.

3. 「내 주제 낱말과 겹치는 것만 남기고 사건·사고류 낱말은 빼는 거르기가 기본이다」 — 모르면 어떤 일이 생길까요?
