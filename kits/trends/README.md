# 인기 키워드 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 인기 키워드 쪽을 켜 줘. 구글 트렌드(한국) 목록을 가져와 /trends/ 와 키워드별 쪽을 만들고, 못 가져오면 마지막 성공본을 쓰는지 확인해 줘.

- **넣는 것 → 나오는 것**: 구글 트렌드 RSS → 키워드 목록 + 키워드마다 관련 보도 제목·링크 쪽
- **2분 안에 보는 결과**: /trends/ 에 오늘의 인기 검색어가 뜨고 누르면 관련 보도 목록이 나옵니다
- **예시 자료가 이미 들어 있습니다**: `kits/trends/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add trends`(지금 켜진 것에 더하기) 또는 `python mix.py trends`(이것만) 후 `python build.py`
- **서버**: 불필요
