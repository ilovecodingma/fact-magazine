# 용어 사전 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 이 저장소에 용어 사전을 만들어 줘. kits/glossary 의 자료 파일 하나에 돈·생활 용어 30개를 쉬운 말로 적고 빌드해서 목록과 용어 쪽이 생기는지 확인해 줘. 숫자·제도는 새로 지어내지 말고 일반적인 뜻만 써.

- **넣는 것 → 나오는 것**: 자료 파일 하나(`kits/glossary/data/terms.json`) → /glossary/ 목록 + 용어마다 쪽(함께 보기 링크 포함)
- **내 주제로 바꾸기**: 들어 있는 **예시 용어 30개(돈·생활 용어)를 지우고** 내 주제의 용어로 교체하세요. 한 덩어리 형식은 `{"term": "용어", "short": "한 줄 풀이", "body": "본문", "see": ["함께 볼 용어"]}` 입니다(10개만 채워도 됩니다). 입력 예: 「kits/glossary/data/terms.json 의 예시 용어를 모두 지우고 <내 주제> 용어 10개로 바꿔 줘. 숫자·제도는 지어내지 말고 일반적인 뜻만 써.」
- **2분 안에 보는 결과**: /glossary/ 에서 용어를 누르면 풀이 쪽이 열리고 아래에 「함께 보기」가 나옵니다
- **사이트 어디에 붙나**: 메뉴 「용어」, /glossary/
- **서버**: 불필요 · **따라 하는 시간**: 약 5분
- **켜기**: `python mix.py glossary`(또는 `site.json` 의 `parts` 에서 `glossary` 켜기) 후 `python build.py`
- **자료 위치**: `kits/glossary/data/`
