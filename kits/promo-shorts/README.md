# 알리기 하네스 3. 글 한 편 → 쇼츠 제목·설명·첫 3초 문장

이렇게 입력하세요: `python -X utf8 run.py 글.md https://내사이트/글주소/ 결과.md`

- 넣는 것: 글.md, 그 글의 주소
- 나오는 것: 결과.md — 제목 후보 3개(글자 수 표시), 설명 2줄 + 주소, 첫 3초 문장 후보 3개
- 2분 안에 보는 결과: 제목은 40자 안쪽인지, 첫 문장이 숫자나 질문으로 시작하는지 본다. 영상 속 숫자가 글과 같은지 확인한다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다. 영상 만들기·올리기는 하지 않는다(문구 파일까지만).
- 한계: 틀에 숫자를 끼운 후보다. 질문이 어색하면 사람이 고친다. 「한도가 얼마일까」는 글이 한도를 다룰 때만 맞다.
