# 하네스 3. 질문형 검색어만 고르기

이렇게 입력하세요: `python -X utf8 run.py 입력.tsv 결과.tsv`

- 넣는 것: 입력.tsv (하네스 2 의 결과 파일을 복사해 이름만 바꿈)
- 나오는 것: 결과.tsv — 겹치지 않고(새 주제) 「언제·얼마·기간·조건·신청·방법…」이 들어 있는 질문형 검색어만
- 2분 안에 보는 결과: 남은 줄이 독자가 실제로 궁금해하는 질문이다. 줄 수가 너무 적으면 하네스 1 의 시드를 늘린다.
- 로그인·계정: 필요 없음. 인터넷도 쓰지 않는다.
