# 오늘의 추천 키트 설명
(에이전트가 독자 눈높이로 풀어 말하는 순서: ①무엇 ②왜 ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
추천 자료(날씨별 목록) + 무료 날씨 서비스 → 오늘 어울리는 3개. /today/ 에 오늘 날씨 한 줄과 추천 3개가 나옵니다(날씨를 못 불러오면 평소 추천).

## ② 왜 이렇게 만들었나(꼭 알아야 할 것)
- 추천 목록은 자료 파일(kits/today/data/items.json)에 날씨 종류별(비·추위·무난 등)로 적어 둡니다.
- 날씨는 무료 서비스(Open-Meteo)에서 쪽을 만들 때 가져옵니다. 못 가져오면 평소 추천으로 넘어가므로 쪽이 비지 않습니다.
- 추천은 빌드(쪽을 만드는 명령) 시점의 날씨 기준입니다. 날씨가 바뀐 뒤 새 추천을 보이려면 다시 빌드해야 합니다.

## ③ 한 번 해 보기
python build.py 후 /today/ 를 열면 오늘 날씨 한 줄과 추천 3개가 나옵니다.

## ④ 바꿔 보기
kits/today/data/items.json 의 「평소」 목록에 내 추천 한 줄을 더하거나, kits/today/data/config.json 의 place·lat·lon 을 내 동네로 바꿔 python build.py 를 다시 돌려 보세요.
