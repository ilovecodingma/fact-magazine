# 오늘의 추천 키트

**이렇게 입력하세요** (Claude Code 에 그대로 붙여 넣기)

> 오늘의 추천 쪽을 켜 줘. kits/today/data/items.json 의 추천 목록을 내 주제로 바꾸고, 빌드해서 /today/ 에 오늘 날씨에 맞는 추천 3개가 나오는지 확인해 줘.

- **넣는 것 → 나오는 것**: 추천 자료(날씨별 목록) + 무료 날씨 서비스 → 오늘 어울리는 3개
- **2분 안에 보는 결과**: /today/ 에 오늘 날씨 한 줄과 추천 3개가 나옵니다(날씨를 못 불러오면 평소 추천)
- **예시 자료가 이미 들어 있습니다**: `kits/today/data/`(숫자·제도를 지어내지 않은 일반 내용). 켜기만 하면 바로 나오고, 내 것으로 바꾸려면 예시를 지우고 내 내용으로 교체합니다.
- **켜기**: `python mix.py --add today`(지금 켜진 것에 더하기) 또는 `python mix.py today`(이것만) 후 `python build.py`
- **서버**: 불필요
