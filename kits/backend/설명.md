# 백엔드(서버) 키트 설명 뼈대
(순서: ①무엇 ②왜(꼭 알아야 할 것) ③한 번 해 보기 ④바꿔 보기 ⑤확인 물음)

## ① 무엇
도커 안의 작은 서버가 찍어 둔 사이트를 내주고 방문자가 쌓는 것(댓글·좋아요·방문·문의·소식 받기)을 JSON 문서로 받는다. 서버가 꺼져 있어도 찍어 둔 화면은 그대로 열린다.

## ② 왜 이렇게 만들었나
- 서버는 방문자가 쌓는 것(댓글·좋아요·방문·문의)을 받는 곳이고, 찍어 둔 화면은 서버가 없어도 열린다
- 쌓인 자료는 JSON 문서 한 건씩 db 에 들어간다(도커 안은 PostgreSQL, 시험은 같은 모양의 파일)
- 서버는 내 PC 안(127.0.0.1)에서만 열려 있다

## ③ 한 번 해 보기
`/키트 backend` — 서버를 임시로 켜서 화면에서 눌러 보고 결과를 확인합니다(도커가 없으면 「도커가 있으면 됩니다」로 건너뜁니다).

## ④ 바꿔 보기
python run.py 서버 로 켜고 http://127.0.0.1:8080/api/health 를 브라우저로 열어 db 가 postgres 로 나오는지 보세요.
