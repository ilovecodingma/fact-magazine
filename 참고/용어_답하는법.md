# 용어를 물으면 (세션이 지킬 것)

책의 CS 용어 216개가 `참고/용어.json`에 있다(`python run.py 용어 <낱말>`로 찾는다). 독자는 책의 긴 질문을 외울 필요가 없다. 용어만 말해도 설명한다.

## 독자가 물을 때
「캐시」, 「포트가 뭐야?」, 「서명 설명해 줘」, 「용어 목록 보여 줘」.
1. `python run.py 용어 <낱말>`로 찾는다. 「목록」이면 `python run.py 용어 목록`(책의 절별)을 보여 준다.
2. 답은 이 순서, 합쳐서 여섯 줄 안으로:
   - **뜻** 한두 문장(자료의 뜻을 기준으로, 길게 강의하지 않는다)
   - **내 것에서는** 독자의 지금 폴더에서 **실제로 확인한 값**: 포트라면 지금 열린 포트와 쓰는 프로그램, 캐시라면 배포한 주소의 응답 머리말과 방금 고친 화면이 안 보이는 이유, 서명이라면 `android_app/`의 버전과 서명 여부(키 파일은 읽지 않는다), 터널이라면 지금 열린 터널 주소 같은 것. 확인할 수 없는 용어면 이 줄을 빼고 그렇다고 말하지 않는다.
   - **관련 절** 한 줄, 그리고 그 개념이 **아홉 단계 가운데 어디에서 나오는지**(번호와 이름) 한 마디
   - **더 물어볼 말** 하나
3. 목록에 없는 용어는 일반 지식으로 짧게 설명하고 「책의 용어 목록에는 없다」고 한 줄로 말한다. 하네스에 없는 기능(쿠버네티스, 복제 등)은 개념으로만 답한다.

## 개념이 실제로 걸린 순간
독자가 묻지 않아도, 아래 순간에는 **해결하면서 한두 문장**으로 그 개념을 먼저 알려 준다. 한 세션에서 같은 용어는 한 번만. 강의로 늘이지 않는다. 독자가 모르는 말을 쓸 때는 풀이를 괄호로 한 번 붙인다.

| 순간 | 알려 줄 용어 |
|---|---|
| 배포했는데 이전 화면이 보인다 | 캐시 |
| 「이미 사용 중인 포트」가 난다 | 포트, 프로세스 |
| 앱을 빌드한다, 서명 키를 만든다 | APK, 서명, 서명 키(잃으면 업데이트 불가) |
| 가게 바깥 주소가 바뀌었거나 닫혔다 | 터널 |
| 임시 주소가 사라졌다 | 임시 배포와 고정 주소 |
| 되돌리거나 복구한다 | 스냅샷과 백업의 차이, 롤백 |
| 한글이 깨져 보인다 | 인코딩(UTF-8) |
| 가게 시험이 통과한다 | 스모크 테스트 |
| 하나 남은 상품에 주문이 겹친다는 이야기가 나온다 | 동시성 |
